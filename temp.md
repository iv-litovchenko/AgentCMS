## Маркеры и пометки `[marker:*]`

Многострочные **личные пометки** в конспекте. В **Preview** (и обзоре темы) рендерятся цветными блоками; в **WYSIWYG** пока остаётся исходный текст. Вставка из палитры редактора: группа **«Маркеры и пометки»**.

### Синтаксис блока

```markdown
[marker:idea]
awn-status: отложено
awn-create: 2026-09-27
приоритет: низкий
---
Текст пометки — несколько абзацев, списки, **выделение**.

[/marker]
```

| Часть | Описание |
|--------|----------|
| `[marker:<type>]` | Тип пометки (иконка и цвет в preview) |
| Строки до `---` | Мета-поля `ключ: значение` |
| `---` | Разделитель мета и тела |
| Тело | Обычный markdown |
| `[/marker]` | Закрытие блока |

### Типы `<type>` (порядок в палитре)

| type | Смысл |
|------|--------|
| `idea` | Идея |
| `important` | Важно |
| `note` | Заметка |
| `todo` | Задача (чеклист) |
| `question` | Вопрос |
| `mistake` | Ошибка |
| `term` | Термин / глоссарий |
| `repeat` | Повторить |

### Мета-поля

**Канонические (все необязательные):**

| Ключ | Назначение |
|------|------------|
| `awn-create` | Когда пометка появилась (дата) |
| `awn-update` | Последнее изменение |
| `awn-status` | Состояние: `открыто`, `закрыто`, `отложено`, … |
| `awn-repeat` | Когда повторить / пересмотреть (дата) |

**Произвольные поля** — любые другие строки `ключ: значение` до `---` (`приоритет`, `источник`, `тег` …). В preview — чипы только со **значением** (имя поля в подсказке). Система их не валидирует.

В мета блока по-прежнему понимаются русские синонимы: `добавлено`, `обновлено`, `статус`, `повторить` (эквиваленты `awn-create`, `awn-update`, `awn-status`, `awn-repeat`).

### Примеры в этом showcase

[marker:idea]
awn-status: отложено
---
Пример **идеи** в справочнике markdown — цвет как у GitHub Alert «Tip».
[/marker]

[marker:question]
awn-status: открыто
awn-create: 2026-09-27
awn-repeat: 2026-10-15
---
Как отличить `[marker:term]` от обычной цитаты?
[/marker]

[marker:repeat]
awn-status: открыто
awn-repeat: 2026-10-01
---
Жизненный цикл `Connection` — схема в голове.
[/marker]
