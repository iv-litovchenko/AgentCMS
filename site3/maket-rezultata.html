Что это за проект

не про агентов — про хранилище

Agent CMS — это не «система для агентов». Это хранилище. Общий ящик, куда всё складывается по одним и тем же принципам — их понимают и вы, и агент.

Вы вместе заходите в этот контейнер и выстраиваете свою экосистему: области, темы, слоты, записи. Агент лазит по всему этому — знает, куда что записать и где что найти. Со временем становится очевидно: фильмы — в «Кино», уроки — в «Английский», рабочие документы — в «Стройка».

Три базовых понятия

папка · запись · sidecar

Раздел

Раздел (папка)

Область или тема — это папка с manifest и слотами. Агент знает, что внутри «Работа → Стройка», и куда класть новые материалы.

Запись

Типизированный файл

Markdown с frontmatter: тип, даты, локация, теги. Человек и агент читают и пишут одинаково — через MCP или интерфейс.

Sidecar

Описание рядом с файлом

Sidecar — отдельный .sidecar.md рядом с картинкой или PDF. В сам файл нельзя вставить текст — sidecar хранит описание, теги и связи.

↗
photo.jpg
↳ photo.sidecar.md — «Фасад дома, июль 2026, привязать к теме Стройка»

Agent Shell · «Говорилка»

единое диалоговое окно — система, телефон, браузер

Один поток сообщений и одно хранилище. Неважно, откуда вы говорите — диалог попадает в thread/ темы, агент понимает контекст и сохраняет результат в нужный слот.

1
Вы говорите или пишете в Shell — с компьютера, телефона или из браузера
2
Сообщение → thread/ одна история диалога для темы, без разрывов между устройствами
3
Агент читает хранилище понимает контекст: области, темы, слоты, записи
4
Ответ + действие находит, записывает, связывает — main/, inbox/, media/…

Индексация и поиск

три слоя — чтобы находить и по словам, и по смыслу, и по полям

Идея: хранилище растёт, а найти нужное можно разными способами — как вы ищете в шкафу: по названию, по смыслу («где-то про питание») или по метке на коробке.

1. Полнотекст

Сканирует пути, frontmatter и тела файлов. «Где упоминается интервальное голодание?» — находит точные совпадения в тексте.

запрос «интервальное голодание» → Здоровье/Питание/main/, фрагмент «польза для метаболизма»

2. Семантический поиск

Ищет по смыслу, не только по словам. «16:8 режим» найдётся рядом с «интервальное голодание», даже если слова не совпадают.

близость 0.98 → Интервальное голодание · 0.91 → 16:8 режим · 0.87 → Метаболизм и сон

3. Каталог по полям

Storage-index — фильтр по frontmatter: тип, теги, локация, статус. Как SQL по свойствам записей.

awn-type = record · awn-tags содержит «питание» · область Здоровье → 3 записи

Подключение по MCP

к любому агенту с поддержкой Model Context Protocol

Хранилище не привязано к одному ИИ. Подключите любой MCP-клиент — Cursor, Claude Desktop, свой агент — и он получит ~70 инструментов: читать, писать, искать, вести диалог.
