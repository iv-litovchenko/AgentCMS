# ЗАЧЕМ ЭТО

Это нашс совместная память для меня (члеовеа) и для тебя ии Агента (1+1))

Agent CMS — общее хранилище для человека и ИИ-агентов. Человек складывает сюда заметки, задачи, идеи, ссылки и файлы. Агент читает и пополняет их, поэтому контекст не теряется между сессиями и между разными агентами.

Человек и агент — совместные пользователи данных (1+1). Ведущая роль принадлежит человеку.
Его слова и структура важнее твоих догадок: сохраняй как есть,
не переписывай и не удаляй по своей инициативе.

## КАК УСТРОЕНО (основные термины)

- Платформа - это вся система в целом
- Хранилище (workspace) - это папка на копьютере (сервере) в которой хранится вся информация в виде md файлов и тд)

Осовная информация хранится в "Хабах"

- Каналы — входящие потоки (Telegram, GitHub, закладки):
сырые идеи, ссылки, задачи на потом.
- Темы — разобранные знания по областям.
- Базы — структурированные данные: задачи, финансы, дневник, привычки.
- Репозитории — подключённые к хранилищу проекты.
- Медиатеки — файлы и картинки.
Сырое попадает в канал, потом разбирается в тему или базу.

## ДОПОЛНИТЕЛЬНО (доплнительные термины)

- Журнал, факты, глоссарий, справочник.
- Крон и heartbeat — задачи по расписанию.
- Зависимости (read_dependencies / write_dependencies) — связи между
записями; проверяй их перед удалением или переносом.
- Vaults, sidecars — подробности в документации.

## Для подробной

## СТАРТ

1. `list_workspaces` → выбери id → `get_session_context({ workspaceId })`.
2. **`workspaceId`** обязателен в каждом workspace-scoped вызове (legacy: `agentId`).
3. Карта workspace: `read_topic_index_toc` или `read_workspace_map` (WS-MAP).
4. Пользователь не назвал путь → `get_ui_focus` (что открыто в UI Agent CMS).
5. Полная документация — скилл `agent-cms` (файл `GLOBAL-SKILL.md`). Если не подключён: `read_platform_doc({ path: "GLOBAL-SKILL.md" })`.
