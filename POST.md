**📂 Что лежит внутри папки**

В прошлом посте мы выяснили, что всё хранится в одной обычной папке. Теперь — в каком виде и из каких частей она состоит.

**📝 Формат**

Закрытой базы нет. Заметка — это `.md`: сверху YAML-поля (тип, теги, статус, связи), ниже текст. Настройки — в `config.yml`, описание папки для агента — в `manifest.md`. Всё открывается любым редактором и кладётся в git. Если CMS пропадёт, данные останутся при вас.

**🧠 Платформа и хранилища**

Проект можно было бы назвать Agent Memory CMS, но память здесь общая — и для агента, и для человека. Поэтому просто Agent CMS.

• **Платформа** — общая основа: типы записей, справочники, настройки.

• **Хранилища** — ваши папки с данными; у каждого агента может быть своя.

**🗂 Восемь частей хранилища**

1. **Каналы входящих** — чаты с агентами, голосовые, выгрузки из почты, Telegram и WhatsApp, интернет. Сначала всё падает сюда, разбираем потом.

2. **Дерево страниц (темы)** — раздел → тема → полка → запись. Структуру строите сами. Подходит для изучения нового: нейросети, ИИ, английский.

3. **Инфоблоки** — таблицы с одинаковыми полями: расходы, контакты, справочники. Аналог БД или Excel.

4. **Медиатека** — любые отдельные документы (подкасты, паспорт, СНИЛС) и нужные скрипты.

5. **Репозитории** — проекты с кодом отдельно от заметок.

6. **Внешние зависимости** — файл `dependencies.csv` со всеми скилами и коннекторами, например из Claude.

7. **Корзина** — отдельный модуль: удалённое можно найти и восстановить.

8. **Настройки** — поведение системы на уровне платформы, хранилища, области или темы.



**🛠 Дополнительно**

Git, облака (Google Drive), виды поиска, реестр запросов.

**🔌 Доступ**

Человек — через интерфейс, агент — через MCP. Файлы одни и те же.

**Итого:** одна папка, `.md` и `.yml`, всё разложено по частям.
