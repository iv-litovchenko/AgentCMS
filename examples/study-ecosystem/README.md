# Экосистема изучения — три слоя

Интерактивные прототипы инструментов вокруг конспектов.

## Три слоя

| Слой | Инструмент | Вопрос |
|------|------------|--------|
| 1 | Mindmap | Что входит в тему? |
| 2 | Roadmap | В каком порядке идти? |
| 3 | Пометки `[мое *]` | Что со мной лично? |

## Запуск

```bash
open examples/study-ecosystem/index.html
```

## Примеры

| # | Файл | Описание |
|---|------|----------|
| 5 | `05-glossary.html` | Глоссарий с поиском и алфавитом |
| 6 | `06-version-tracker.html` | История версий конспекта |
| 7 | `07-timeline.html` | Таймлайн релизов + личный путь |
| 8 | `08-comparison-tables.html` | X vs Y таблицы |
| 9 | `09-note-templates.html` | Шаблоны Java / English / History |
| 10 | `10-roadmap-mermaid.html` | Roadmap v2: Mermaid + YAML статусы |
| 11 | `11-mindmap-markers.html` | Клик по узлу → пометки раздела |
| 12 | `12-spaced-repetition.html` | Экспорт `[мое повторить]` с датами |

Ядро (примеры 1–4): `../mindmap/`, `../study-markers/`, `../roadmap/`.
