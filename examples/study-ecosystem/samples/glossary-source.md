# Java — выдержки из конспектов

## JVM

**JVM** — Java Virtual Machine, исполняет байткод.
**Bytecode** — промежуточный код между .java и машинным кодом.

## Generics

**Generics** — параметризация типов: `List<String>`.
**Wildcard** — `? extends T` и `? super T` для гибкости API.
**PECS** — Producer Extends, Consumer Super.

## ООП

**Полиморфизм** — один интерфейс, разные реализации.
**Инкапсуляция** — сокрытие внутреннего состояния объекта.
