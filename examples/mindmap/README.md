# Mindmap из Markdown — HTML-примеры

Интерактивные прототипы для ТЗ: скрипт строит майнд-карту из markdown-конспектов.

## Запуск

Откройте в браузере:

- [index.html](index.html) — навигация
- [01-single-file.html](01-single-file.html) — **режим 1**: один файл, H1→H2→H3
- [02-folder-with-links.html](02-folder-with-links.html) — **режим 2**: папка файлов + перекрёстные ссылки

```bash
open examples/mindmap/index.html
# или
npx serve examples/mindmap
```

## Входные данные (примеры)

| Режим | Путь | Описание |
|-------|------|----------|
| 1 | `sample-single/java-overview.md` | Один файл с заголовками 1–3 уровня |
| 2 | `sample-folder/*.md` | Несколько файлов-подтем + `[ссылки](file.md#anchor)` |

## Что показывают примеры

- **Центр** — H1 (режим 1) или название темы/папки (режим 2)
- **Крупные ветки** — H2 (режим 1) или файл/его заголовок (режим 2)
- **Листья** — H3
- **Пунктир** — markdown-ссылки между узлами, вне иерархии
- Панорама, зум, подсветка при наведении

## Для скрипта (дополнение к ТЗ)

Рекомендуемые CLI-флаги:

```bash
node mindmap.js --input notes/java.md --output map.html
node mindmap.js --input notes/ --output map.png --format png
node mindmap.js --input notes/ --xref --collapse-files
```

Дополнительно стоит зафиксировать:

1. **Якоря** — `file.md#заголовок` резолвится в slug заголовка (GitHub-style).
2. **Имя ветки** — приоритет: первый `# H1` в файле, иначе имя файла без `.md`.
3. **Глубина** — только H1–H3; H4+ игнорируются или сворачиваются в родительский H3.
4. **Форматы вывода** — `html` (интерактив), `svg`, `png` (через headless).
5. **Битые ссылки** — предупреждение в stderr, линия не рисуется.
