Mindmap из Markdown

Интерактивные HTML-примеры для технического задания

Режим 1

Один файл → одна карта

H1 — центр, H2 — ветки, H3 — листья. Пример: sample-single/java-overview.md

 Режим 2

Папка файлов + перекрёстные ссылки

Каждый .md — крупная ветка, внутри H2/H3. Пунктир — markdown-ссылки между узлами.

 Режим 3

Личные пометки в конспектах

6 типов: [мое повторить], [мое вопрос], [мое заметка], [мое важно], [мое ошибка], [мое идея].

 Режим 4

Дорожная карта обучения

H2 — этапы слева направо, цвет по статусу. Параллельные ветки через [параллельная группа].
