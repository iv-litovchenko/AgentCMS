# Examples7 — центральное содержимое: обзор ноды

## Задача

25 прототипов **центральной области workspace** в режиме «Обзор ноды» — когда пользователь открывает `*.node.md` и хочет **быстро понять**, что это за нода, куда перейти дальше, и что в памяти.

Examples5 отвечал на вопрос «где Save / YAML / редактор».  
Examples7 — «как показать **превью, метаданные, память, подразделы и навигацию по режимам**».

## Что сравниваем

| Блок | Смысл |
|------|--------|
| **Hero** | Превью + название + `AWN-TYPE` + `AWN-DESC` |
| **Meta** | Сетка свойств frontmatter |
| **Память** | Карточки internal / external / tabular |
| **Подразделы** | Дочерние ноды (контейнер) |
| **Навигация** | Быстрый переход: Описание, Память, Медиа, Граф |

В каждом варианте переключатель **Контейнер / Solo** — одна раскладка, разная наполненность (у solo нет подразделов).

## Рекомендация (вариант 24)

Близко к текущему Agent CMS после фикса дублирования:

1. Крошки: `Обзор ноды / … / *.node.md`
2. Hero с превью слева (120px) + заголовок
3. Meta grid — компактно, без дубля «Описание» если есть `AWN-DESC`
4. Блок **🧠 Память** с карточками — **без** повторной секции «Память» в ссылках
5. Подразделы — жёлтые карточки для папок
6. Ссылки на режимы — только ⚙️ Настройки, 📎 Файлы, 🧭 Навигация
