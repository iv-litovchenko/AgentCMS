# Menu static footer — UI variants

10 standalone HTML demos for `#menu-static-footer` toggle styling.

Open via CMS dev server (recommended):

```
http://127.0.0.1:3000/examples/menu-static-footer/
```

Symlink: `public/examples/menu-static-footer` → `examples/menu-static-footer`.

`file://` may be blocked by the browser for local scripts/styles.

| # | Folder | Idea |
|---|--------|------|
| 01 | `01-current` | Current production look |
| 02 | `02-pill` | Short rounded pill |
| 03 | `03-segmented` | Segmented «Система / Дополнительно» |
| 04 | `04-handle-bar` | Bottom drawer handle |
| 05 | `05-icon-row` | Section emoji preview |
| 06 | `06-ghost-link` | Minimal text link |
| 07 | `07-chip-preview` | Collapsed chips preview |
| 08 | `08-accent-band` | Indigo accent header |
| 09 | `09-status-dots` | Title + status dots |
| 10 | `10-compact-badge` | Short title + count badge |

Shared: `shared.css`, `shared.js`.
