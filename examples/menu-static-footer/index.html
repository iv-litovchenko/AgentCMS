Системные и дополнительные секции

10 вариантов оформления нижнего блока сайдбара #menu-static-footer. Каждый файл — отдельный HTML с моком меню. Кликайте переключатель, чтобы свернуть/развернуть.

Как открыть: через CMS-сервер — http://127.0.0.1:3000/examples/menu-static-footer/ (запустите npm start или ваш обычный порт). Прямой file:// в браузере может не работать из‑за ограничений безопасности.
