# Examples5 — форма редактирования AGENTS.md и ноды

## Два типа документа

| Тип | Файл | Название | Удаление |
|-----|------|----------|----------|
| **Агент** | `AGENTS.md` | Фиксировано, нельзя переименовать | Обычно нет (или «сброс») |
| **Нода** | `_.node.md` | Редактируемое поле + суффикс | «Удалить ноду» |

Во всех прототипах переключатель **AGENTS.md / Нода** показывает, как одна и та же раскладка ведёт себя для обоих случаев.

## Что сравниваем

- **Сохранить** — primary, часто справа или в липкой зоне.
- **Свойства** — YAML / форма полей (не путать с «настройками ноды» в дереве).
- **Удалить** — danger, реже и дальше от Save.
- **Содержимое** — textarea, preview или вкладки; не зажимать действиями.

## Рекомендация (вариант 24)

Близко к текущему Agent CMS после упрощения shell:

1. Крошки + селект режима (память / настройки).
2. Слой **названия**: для AGENTS — badge + 🔒; для ноды — input.
3. Слой **свойств** — отдельная плита, кнопка «Свойства» только если панель свёрнута.
4. Слой **содержимого** — toolbar Preview/Source, редактор на остаток высоты.
5. **Сохранить** в строке названия; **Удалить** только для ноды и только в режиме описания/контента.
