# Блоки `[marker:*]` в markdown

Многострочные пометки внутри конспекта (группа **Markers** / «Пометки»).

## Синтаксис

```markdown
[marker:question]
awn-status: открыто
awn-create: 2026-09-20
awn-update: 2026-09-25
повторить: 2026-10-01
---
Текст пометки (несколько абзацев, списки).

Вторая строка.
[/marker]
```

- **Открытие:** `[marker:<type>]` — тип задаёт иконку в дашборде.
- **Мета (до `---`):** необязательные канонические поля и любые свои `ключ: значение`.
- **Разделитель:** `---` перед телом.
- **Закрытие:** `[/marker]`.

### Канонические поля (все необязательные)

| Ключ | Назначение |
|------|------------|
| `awn-create` | когда пометка появилась |
| `awn-update` | последнее изменение |
| `awn-status` | состояние (`открыто`, `закрыто`, `отложено`, …) |

Любые другие строки `ключ: значение` сохраняются как произвольные поля (например `повторить: 2026-10-01`, `приоритет: высокий`).

В дашборде `awn-create` / `awn-update` / `awn-status` показываются как чипы дат и статуса. Остальные ключи — отдельные чипы `ключ: значение`.

Для строковых пометок `[мое *]` + `[мое мета]` те же ключи поддерживаются; старые русские имена (`добавлено`, `обновлено`, `статус`) по-прежнему понимаются.

## Типы (`<type>`)

| type | В дашборде | Иконка |
|------|------------|--------|
| `repeat` | мое повторить | ↻ |
| `question` | мое вопрос | ? |
| `note` | мое заметка | ✎ |
| `term` | мое термин | § |
| `important` | мое важно | ! |
| `mistake` | мое ошибка | ✕ |
| `idea` | мое идея | ★ |
| `todo` | мое todo | ☐ |

## Совместимость

- Строки `[мое повторить]: …` + `[мое мета]` по-прежнему собираются.
- `collect-markers.js` объединяет оба формата в один список.
- Блоки помечаются в UI бейджем `[marker:question]` и синей полосой слева.
