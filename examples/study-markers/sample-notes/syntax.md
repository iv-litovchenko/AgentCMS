# Основы синтаксиса Java

## Типы данных

Примитивы: `int`, `long`, `double`, `boolean`, `char`.
Ссылочные типы хранят адрес объекта в heap.

[мое повторить]: разница между == и equals для объектов

[мое важно]: для строк всегда использовать .equals(), не ==

### Generics

`List<String>` — параметризованный тип. Wildcards: `? extends T`, `? super T`.

[мое вопрос]: когда использовать bounded wildcard extends, а когда super?

[мое заметка]: PECS — Producer Extends, Consumer Super

## Операторы

Арифметика, сравнение, логика. Оператор `instanceof` проверяет тип.
