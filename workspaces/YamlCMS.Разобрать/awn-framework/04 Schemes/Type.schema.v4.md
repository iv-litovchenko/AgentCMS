# Type.schema — справочник полей (v4)

Каждое поле описано отдельной таблицей-карточкой. Сложные перечисления (значения, неймспейсы) вынесены в отдельные файлы-справочники рядом.

## Поля шапки

| Поле     | `AWN-ID`                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------------- |
| Тип      | string (immutable)                                                                                      |
| Значение | UUID v4 в нижнем регистре, в двойных кавычках. Пример: `"5f3a8c12-4b9d-4321-9a2b-77b1c3e88e10"`         |
| Описание | Машинный уникальный идентификатор. Создаётся один раз и **не меняется** при переименовании/перемещении. |

| Поле     | `AWN-SLUG`                                                                                            |
| -------- | ----------------------------------------------------------------------------------------------------- |
| Тип      | string (mutable)                                                                                      |
| Значение | `NAMESPACE/...`, верхний регистр, разделитель `/`. Примеры и неймспейсы — [AWN-SLUG](AWN-SLUG.md).    |
| Описание | Человекочитаемое имя типа. Связи между файлами идут по `AWN-ID`, а не по slug.                        |

| Поле     | `AWN-TYPE`                                                          |
| -------- | ------------------------------------------------------------------- |
| Тип      | enum (mutable)                                                      |
| Значение | `Folder` или `File`                                                 |
| Описание | Форма ноды. `Folder` — маркер-файл внутри папки. `File` — один `.md`. |

| Поле     | `AWN-ALLOW-CHILDREN`                                                          |
| -------- | ----------------------------------------------------------------------------- |
| Тип      | bool (mutable)                                                                |
| Значение | `true` или `false`                                                            |
| Описание | Разрешены ли дочерние ноды. `true` — контейнер; `false` — конечный «тупик».   |

| Поле     | `AWN-LAYER`                                                                  |
| -------- | ---------------------------------------------------------------------------- |
| Тип      | int (mutable)                                                                |
| Значение | Целое от `0` до `5`. Расшифровка слоёв — [AWN-LAYER](AWN-LAYER.md).          |
| Описание | Архитектурный слой контекста, к которому относится тип.                      |

| Поле     | `AWN-NAME`                                                                |
| -------- | ------------------------------------------------------------------------- |
| Тип      | string (mutable)                                                          |
| Значение | Короткое имя. Примеры: `Workspace`, `Space`, `Part`, `Volume`.            |
| Описание | Человекочитаемое короткое имя типа. Используется в заголовках и UI.       |

| Поле     | `AWN-DESC`                                          |
| -------- | --------------------------------------------------- |
| Тип      | string (mutable)                                    |
| Значение | 1–2 строки текста.                                  |
| Описание | Краткое описание типа — что это и зачем нужно.      |

| Поле     | `AWN-REGISTRY`                                                                                                                          |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Тип      | bool (mutable)                                                                                                                          |
| Значение | `true` или `false`                                                                                                                      |
| Описание | Регистрируется ли тип в `awn.registry.md`. `true` — структурные ноды (`COMPONENT/SPACE`, `COMPONENT/PART`); `false` — память, спутники, external. |

## Справочники

- [AWN-LAYER](AWN-LAYER.md) — расшифровка архитектурных слоёв `0`–`5`.
- [AWN-SLUG](AWN-SLUG.md) — неймспейсы slug-ов.

## Генерация `AWN-ID`

macOS / Linux, без зависимостей:

```bash
uuidgen | tr 'A-Z' 'a-z'
```

Результат — UUID v4 в нижнем регистре, формат `xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx`. Записать в `AWN-ID` в двойных кавычках. После создания **не менять**.
