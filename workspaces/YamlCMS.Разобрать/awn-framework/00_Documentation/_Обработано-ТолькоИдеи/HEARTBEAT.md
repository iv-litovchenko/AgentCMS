# HEARTBEAT.md

> Файл задач для периодической проверки агентом. Оставь пустым — heartbeat-вызовы пропускаются. Добавь задачу — агент выполняет её по расписанию или при старте полной сессии.

---

## Как работает

- Агент читает этот файл при каждом heartbeat-прогоне.
- Активные задачи (`- [x]`) выполняются; выполненные отмечаются или архивируются.
- Задачи-идеи (`- [ ]`) ждут активации — расставь приоритет или подключи к крону.
- **Cron-задачи системы:** список активных cron-нод с `AWN-AUTOMATIZATION: true` — см. таблицу в `AGENTS.NODES.md` раздел «Ноды с расписанием». При heartbeat-вызове агент не выполняет их самостоятельно — они управляются планировщиком окружения.
