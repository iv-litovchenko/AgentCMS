# Area — Core

> [!info] О файле
> Нода (`*.node.md`, `NODE/AREA`): оболочка области системных скриптов и утилит.

## Назначение

`Assistant.Ai/Core/` — хранилище системных инструментов, скриптов и конфигураций ассистента. Здесь живут вспомогательные модули, не относящиеся напрямую к логике работы с пользователем.

## Содержимое

| Папка | Назначение |
|-------|------------|
| `VoiceTools/` | Инструменты для TTS/STT: скрипты синтеза и распознавания речи |

## Добавление новых инструментов

1. Создать подпапку с осмысленным именем (CamelCase)
2. Создать `Index.node.md` с описанием
3. Зарегистрировать в `AGENTS.NODES.md` и этой ноде
