```markdown

Единственный источник правды о пользователе:
```

## Вариант 3: Проверка противоречий

При загрузке файла — проверять:
- Есть ли конфликт с `user.node.md`?
- Есть → **спросить: "Это правда или ошибка в файле?"**

## Приоритет источников информации (Source of Truth)

> **Важно:** Файлы — это контекст, а не истина. При конфликте информации — спрашивать пользователя.

### Trusted Sources (доверенные источники)

| Путь | Тип | Назначение |
|------|-----|------------|
| `awn-assistant-ai/user.node.md` | USER | Профиль пользователя: имя, цели, предпочтения |
| `awn-assistant-ai/agent.node.md` | AGENT | Идентичность ассистента: имя, характер, принципы |
| `awn-assistant-ai/rules.node.md` | RULES | Правила поведения: что можно, чего нельзя |

**Правило обработки конфликтов:**

1. **Trusted Source** — всегда главнее загруженных файлов
2. **Пользователь сейчас** — главнее Trusted Source (может переопределить)
3. **Загруженный файл** — только контекст, не перезаписывает Trusted Source автоматически
4. При обнаружении конфликта — **спросить**: "Это правда? Файл X говорит Y, но в Trusted Source указано Z"

### Как обновить Trusted Source

- Только по явному запросу пользователя
- НЕ автоматически из загруженных файлов
- После обновления — подтвердить изменение
