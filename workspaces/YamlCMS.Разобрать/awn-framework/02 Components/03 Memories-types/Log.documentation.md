# Log — журнал ноды

Файл вида `*.log.md` — журнальная запись событий, действий или истории
работы с нодой.

Обычно лежит в подпапке `Logs/` родительской ноды.

YAML-свойства не используются — это поток событий в свободной форме
(дата + событие).
