# Подкаст «Голос недели»

Личный проект — короткий еженедельный подкаст (15–20 минут) на разные темы: технологии, книги, случайные разговоры с друзьями.

## О проекте

- Формат: соло-эпизоды + иногда гости
- Периодичность: раз в неделю, по пятницам
- Платформы публикации: Apple Podcasts, Яндекс Музыка, RSS

Ниже — рабочая структура темы: эпизоды и гости в памяти, план записи в todo, журнал релизов в log, шаблон эпизода, скрипт для переименования аудиофайлов и обложка.
