# Дата и время

```php
<?php
declare(strict_types=1);

$now = new DateTimeImmutable('now', new DateTimeZone('Europe/Moscow'));
$formatted = $now->format('Y-m-d H:i:s');

$tomorrow = $now->modify('+1 day');
$interval = $now->diff($tomorrow);
```

## DateTimeImmutable vs DateTime

Предпочитайте **Immutable** — методы `modify` возвращают новый объект.

## Carbon (пакет)

```php
use Carbon\Carbon;
echo Carbon::parse('2026-06-06')->locale('ru')->isoFormat('D MMMM YYYY');
```
