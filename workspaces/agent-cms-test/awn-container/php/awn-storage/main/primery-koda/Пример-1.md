# Пример 1 — Hello World и strict types

Файл: `hello.php`

```php
<?php
declare(strict_types=1);

function greet(string $name): string {
    return "Hello, {$name}!";
}

echo greet('PHP');
echo PHP_EOL;
```

## Запуск

```bash
php hello.php
```

## Ожидаемый вывод

```
Hello, PHP!
```

## Задание

- Добавить аргумент `$locale` (`ru` / `en`).
- Обработать пустое имя через `InvalidArgumentException`.
