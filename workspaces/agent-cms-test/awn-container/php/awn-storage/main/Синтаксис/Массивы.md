# Массивы

```php
<?php
declare(strict_types=1);

$list = [1, 2, 3];
$map = ['name' => 'PHP', 'ver' => 8];

$list[] = 4;
$map['ext'] = 'mbstring';

// spread (8.1+)
$merged = [...$list, 5, 6];
```

## Полезные функции

| Функция | Назначение |
|---------|------------|
| `array_map` | map |
| `array_filter` | filter |
| `array_reduce` | reduce |
| `array_column` | колонка из массива записей |
| `array_key_exists` | ключ есть? |

## Итерация

```php
foreach ($map as $key => $value) {
    echo "{$key}: {$value}\n";
}
```
