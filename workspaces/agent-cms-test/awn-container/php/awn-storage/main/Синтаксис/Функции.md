# Функции

```php
<?php
declare(strict_types=1);

function greet(string $name, string $prefix = 'Привет'): string {
    return "{$prefix}, {$name}!";
}

$double = fn(int $n): int => $n * 2;
```

## Именованные аргументы (8.0+)

```php
greet(name: 'PHP', prefix: 'Hello');
```

## Variadic

```php
function sum(int ...$nums): int {
    return array_sum($nums);
}
```

## Type hints для массивов

```php
/** @param list<string> $tags */
function renderTags(array $tags): string {
    return implode(', ', $tags);
}
```
