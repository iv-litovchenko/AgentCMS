# Интерфейсы

```php
<?php
declare(strict_types=1);

interface Logger {
    public function info(string $message): void;
    public function error(string $message): void;
}

final class FileLogger implements Logger {
    public function __construct(private string $path) {}

    public function info(string $message): void {
        file_put_contents($this->path, "[INFO] {$message}\n", FILE_APPEND);
    }

    public function error(string $message): void {
        file_put_contents($this->path, "[ERROR] {$message}\n", FILE_APPEND);
    }
}
```

## Зачем

- Контракт без привязки к реализации.
- Удобно для DI-контейнеров (Symfony, Laravel).
- Легко подменить mock в тестах.
