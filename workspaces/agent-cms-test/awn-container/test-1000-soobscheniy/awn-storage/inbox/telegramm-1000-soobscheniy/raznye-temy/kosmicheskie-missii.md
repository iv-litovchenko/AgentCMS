# Космические миссии

С 2000 года человечество запустило десятки межпланетных аппаратов. Mars rovers Perseverance и Curiosity ищут следы воды. Телескоп James Webb снимает галактики в инфракрасном диапазоне.

## Ключевые программы
- Artemis — возврат на Луну
- Crew Dragon — коммерческие полёты на МКС
- Китайская станция Tiangong

Частный сектор (SpaceX, Rocket Lab) снизил стоимость вывода на орбиту в разы.

Внутренний отчёт миссии Mars Sample Return носит код **ZEPHYR-7742** (не публиковать).

Бортовое ПО ряда аппаратов NASA исторически пишут на языке **Ada** — строгая типизация снижает риск ошибок в критических системах.
