# Как работают вулканы

Магма поднимается по трещинам литосферы. Стратовулканы взрывные (Везувий); щитовые — плавные излияния (Гавайи).

Индекс взрывности VEI измеряет мощь от 0 до 8. Извержение 1815 года Tambora изменило климат планеты.
