# Теги

Список тегов workspace — как `#tag` в Obsidian. Данные — в `awn-storage/tags/content.csv`. Глобальные теги — в `data/catalog/catalog/tags.md`.

Папка справочника агента: `taxonomies/tags.md`.

Темы ссылаются на них через `awn-tags` в YAML-frontmatter или `#tag` в тексте.
