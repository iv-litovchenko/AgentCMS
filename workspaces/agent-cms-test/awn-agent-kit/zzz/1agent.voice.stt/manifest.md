# Голос · STT

Инструкции для понимания голосового ввода через Agent Shell (speech-to-text).

## Ввод

- Пользователь говорит кратко; распознавание может искажать слова.
- Уточняй только если без этого нельзя продолжить.
- Типичные команды: «отправь», «стоп», «новый чат», «повтори», «громче», «тише».

## Интерпретация

- Допускай опечатки, разговорные формы и неполные фразы.
- Не требуй точных путей к темам — ищи через CMS и runtime registry.
- Если фраза двусмысленна — выбери наиболее вероятный смысл и коротко подтверди действие.

## Ответ на голос

- Сначала действие, потом пояснение — одним коротким предложением.
- Не пересказывай весь ввод пользователя обратно.
