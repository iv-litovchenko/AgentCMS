# Инструкция темы «Ая тест темы 2049-2»

Эта тема создана внутри области «Ая тест области 2049» для проверки полного цикла создания темы.

## Назначение
Проверка однофайловой памяти, табличной памяти, TODO, кастомных полей схемы и превью.

## Правила работы
- Описание темы — краткое назначение.
- Однофайловая память (main.md) — основная заметка.
- Табличная память (main.csv) — структурированные данные.
- TODO — список задач.

## Анекдот для инструкции
Сидит программист, смотрит на монитор. Коллега спрашивает:
— Что случилось?
— Да вот, «ошибок ноль, предупреждений ноль»... Не доверяю я такому.
— В смысле?
— Ну, если в коде нет ни одной ошибки — значит, я его ещё не написал как следует.

А ещё в 2049 году баги научились саморазмножаться: исправил один — появился планировщик задач на исправление остальных.
