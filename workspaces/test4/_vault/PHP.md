# PHP

**Назначение темы** — учебный workspace по PHP 8.x: от синтаксиса до практики с БД и фреймворками.

## Карта памяти (`_s.PHP/`)

| Слой | Режим в UI | Файл / папка |
|------|------------|--------------|
| Однофайловая | internal | `Content.md` — связный конспект |
| Многофайловая | external | `Content/` — **30+ заметок** по разделам (см. `Content/README.md`) |
| Табличная | tabular | `Content.csv` — функции, версии, фреймворки |
| Входящие | inbox | `Inbox/` — черновики до разбора |
| Источники | references | `Referenses/` — ссылки и цитаты |
| Медиа | media | `Assets/` — картинки, PDF + sidecar |
| Скрипты | scripts | `Scripts/` — lint, запуск примеров |
| Артефакты | artefacts | `Artefacts/` — экспорт, сборки |
| Временные | temp | `Temp/` — одноразовые файлы |
| Конфиг | configs | `Config.yml` |
| Задачи | todo | `Todo.md` |
| Окружение | env | `.env` |
| Превью | node-preview | `Preview.png` |
