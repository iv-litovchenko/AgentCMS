# Типы данных в PHP

## Скаляры

| Тип | Пример | Проверка |
|-----|--------|----------|
| `bool` | `true`, `false` | `is_bool()` |
| `int` | `42`, `-1` | `is_int()` |
| `float` | `3.14` | `is_float()` |
| `string` | `'text'`, `"{$x}"` | `is_string()` |

## Составные

| Тип | Пример |
|-----|--------|
| `array` | `[1, 2]`, `['k' => 'v']` |
| `object` | `new stdClass()` |
| `callable` | `strlen(...)`, `[$obj, 'method']` |

## PHP 8+

```php
function parseId(string|int $id): int {
    return is_int($id) ? $id : (int) $id;
}

enum Status: string {
    case Draft = 'draft';
    case Published = 'published';
}
```

## Приведение

```php
$n = (int) '42';
$ s = (string) 100;
$ list = array_values((array) $object);
```

С `declare(strict_types=1)` автоматическое приведение аргументов функций отключается.
