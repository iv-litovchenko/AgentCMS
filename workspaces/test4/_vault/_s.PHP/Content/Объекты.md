# Объекты

Объект — экземпляр класса. Создание через `new`:

```php
<?php
declare(strict_types=1);

$post = new Post(1, 'Hello PHP', 'Текст статьи…');
echo $post->title;
echo $post->excerpt(80);
```

## Свойства и методы

- Публичные — доступ снаружи.
- Private/protected — инкапсуляция; снаружи — через методы.

## Clone и serialize

```php
$copy = clone $post;
$data = serialize($post);
$restored = unserialize($data);
```

Для DTO предпочтительнее явный `toArray()` / `fromArray()` вместо `serialize`.
