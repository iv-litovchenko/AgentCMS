## if / elseif / else

```php
if ($score >= 90) {
    $grade = 'A';
} elseif ($score >= 70) {
    $grade = 'B';
} else {
    $grade = 'C';
}
```

## match (PHP 8+)

```php
$label = match ($status) {
    'draft' => 'Черновик',
    'published' => 'Опубликовано',
    'archived' => 'Архив',
    default => 'Неизвестно',
};
```

## foreach и break/continue

```php
foreach ($items as $item) {
    if ($item['skip']) continue;
    if ($item['stop']) break;
    process($item);
}
```

## try / catch / finally

```php
try {
    $pdo->beginTransaction();
    // ...
    $pdo->commit();
} catch (PDOException $e) {
    $pdo->rollBack();
    throw $e;
}
```
