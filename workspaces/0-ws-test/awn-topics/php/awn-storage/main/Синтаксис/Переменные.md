# Переменные

```php
<?php
declare(strict_types=1);

$count = 42;
$price = 19.99;
$active = true;
$title = 'PHP';
$items = ['a', 'b', 'c'];
$user = ['id' => 1, 'name' => 'Anna'];
```

## Правила

- Имена: `$camelCase` или `$snake_case` — выберите стиль проекта.
- Константы: `const MAX = 100;` или `define('MAX', 100);`
- При `strict_types` не полагайтесь на неявное приведение.

## Полезное

```php
$host = $_ENV['DB_HOST'] ?? 'localhost';
$name = $user['name'] ?? 'Guest';
```
