## Best Practices по организации агента

1. **Одна нода = одна ответственность** (Single Responsibility)
Не смешивайте разные задачи в одном файле — разводите их по дереву.

2. **Используй Parts** для разделов внутри крупной темы, а не плодите десятки мелких нод.

3. **Иерархия**:
    * Корневые ноды — крупные области (Личность, Продукты, Навыки, Исследования)
    * Дочерние ноды — конкретные проекты/темы
    * Parts — подразделы внутри одной темы

4. **YAML-свойства**:
Используйте активно: `color`, `tags`, `priority`, `owner`, `status`.

5. **Превью** (_Preview/preview.*) — очень помогает в режиме "Карточки".

6. **Sidecar** для всех важных медиафайлов.
Для всех важных медиафайлов в `_Assets` — markdown-заметка рядом с файлом.

7. **Глубина вложенности**
Не плодите слишком глубокую вложенность** (>4 уровней — уже тяжело навигировать).

8. **Отделяй инструкции** (_.node.md) от данных (_Content/ и _.node.main.md).

Инструкции vs данные

| Тип | Где хранить |
| --- | --- |
| **Инструкции** | `_.node.md` |
| **Данные** | `_Content/`, `_.node.main.md` |
