## **Если совсем простыми словами**

**Agent CMS** — это общий цифровой шкаф, где человек и его AI-помощник хранят одни и те же знания, документы, заметки и задачи. Человек раскладывает информацию руками, а AI может читать её, искать, дополнять и самостоятельно работать с ней.

![20260821201530](awn-storage/assets/pasted/20260821201530.png)![20260821201710](awn-storage/assets/pasted/20260821201710.png)![20260821201721](awn-storage/assets/pasted/20260821201721.png)![20260821201736](awn-storage/assets/pasted/20260821201736.png)**Аналогия**
Представь огромный умный шкаф + рабочий стол.

* **Workspace** — весь шкаф.
* **Area** — большие отделы шкафа: «Работа», «Личное», «Проекты».
* **Topic** — конкретная полка/папка: «Agent CMS», «Путешествие», «Книга».
* **Slot** — разные ящики внутри полки: «Основное», «Входящие», «Фото», «Заметки», «Диалоги».
* **Content** — конкретный лист бумаги или файл в ящике.

Но главное отличие от обычного Google Диска:

**У этого шкафа есть AI, который имеет доступ к тому же шкафу, что и ты.**

То есть не существует отдельно «твоих файлов» и «файлов AI». Вы работаете с одной памятью.

### Какую проблему решает

Сейчас информация человека обычно разбросана:

**Telegram → заметки → Google Drive → Obsidian → файлы → браузер → голова → задачи.**

AI при этом часто существует отдельно и не понимает, где лежит твоя настоящая информация.

Agent CMS пытается сделать **одно общее пространство**, где:

**человек → информация → AI → действия связаны между собой.**

Это особенно полезно человеку, который хочет иметь постоянного AI-помощника, а не просто чат, которому каждый раз приходится объяснять всё заново.

### 3 главные сильные стороны

1. **Одна память для человека и AI** 
    Ты и AI смотрите на одни и те же данные. AI не просто отвечает в чате — он может работать с твоим рабочим пространством.
2. **Свободная структура** 
    Каждая тема может иметь собственные поля и правила. Например, тема «Автомобили» может иметь марку, цену, пробег и дату покупки, а тема «Книги» — автора, жанр и рейтинг.
3. **Это не просто хранилище** 
    Темы могут сами запускать действия по расписанию или периодически проверяться AI. Поэтому система постепенно превращается из «умного диска» в рабочую среду для автономного AI.

### **Если совсем коротко:**

**Agent CMS = Google Drive + Notion + память AI, но всё это находится в одном общем пространстве.**

## ![20260821201652](awn-storage/assets/pasted/20260821201652.png)Claude - описание

Честно — система продумана, но выглядит немного "инженерной", то есть сделана скорее для агентов и разработчиков, чем для обычного человека с ходу.

**Как бы я описал её кратко:**

Это гибрид CMS и общей памяти между человеком и AI-агентом. По сути — единое дерево контента (страницы → слоты → записи), которое одновременно видит и редактирует и человек через UI, и агент через MCP-инструменты. Никакого "два разных мира — файлы агента отдельно, заметки человека отдельно" — всё в одном месте, на одном языке.

**Ключевая идея, которая мне нравится:** разделение на три сущности — Page (узел меню) → Slot (тип хранилища: заметки, входящие, медиа, скрипты...) → Content (сам файл). Это не просто папки с файлами, а модель со схемами полей, типами, фронтматтером — то есть по сути мини-CRM-конструктор, где из любой темы можно сделать структурированную сущность с своими полями (что я видел в теме "Тест всех свойство" — там прямо демонстрация всех типов полей: даты, координаты, цвета, повторители и т.д.).

**Что особенно продумано:**

* Inbox с триажем (входящие → потом решаешь, куда это отправить)
* "Доп. материалы записи" — у каждой записи может быть своя личная папка с файлами
* Индексы (семантический + полнотекстовый + SQL-подобный по полям) — то есть по этому не нужно вручную бродить по дереву
* Cron/heartbeat — темы могут "оживать" по расписанию, то есть это не просто хранилище, а платформа для автономных агентных процессов

**Если совсем просто, одной фразой:** это как Notion, скрещенный с файловой системой и API для AI-агента, где агент и человек работают в одном пространстве, а не в параллельных.

Из минусов — это явно тестовый/демо-workspace (судя по названиям тем вроде "555", "9", "pukpku"), так что реальную мощь системы сложно оценить, не видя её в боевом использовании — вот crm-studio выглядит как единственный "настоящий" кейс здесь.
