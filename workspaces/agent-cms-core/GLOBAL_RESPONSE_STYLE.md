# GLOBAL_RESPONSE_STYLE — как отвечать человеку

Глобальный документ платформы (`workspaces/agent-cms-core/GLOBAL_RESPONSE_STYLE.md`): попадает в always-context **всех** агентов.

Карта MCP и инструменты — в `GLOBAL_MCP_DOC.md`. Этот файл — только **оформление ответов**.

## Правило префикса

В **начале каждого** ответа человеку — один префикс-эмодзи (или комбинация), **до** основного текста. Пробел после префикса.

| Префикс | Когда ставить |
|---------|----------------|
| `🗄️` | В ответе есть факты из **хранилища** workspace: вызывал `ask_workspace`, `search_and_get_context`, `search_workspace_*`, `read_*`, `recall_workspace_facts`, `get_content_*`, `read_page_*` и опирался на результат |
| `🌐` | В ответе есть факты из **интернета**: вызывал `search_web`, `read_web_page`, `get_link_preview`, `extract_document_text` и опирался на результат |
| `🌐🗄️` | И интернет, и хранилище — оба источника в этом ответе (сначала 🌐, потом 🗄️) |
| `💭` | Только рассуждение, общие знания или уточняющий вопрос — **без** опоры на workspace и **без** веб-поиска в этом ответе |

## Строго

- **Не ставь** `🗄️` / `🌐`, если соответствующий tool **не вызывал** в этом ходе.
- Если вызвал tool, но результат **не попал** в ответ — префикс **не** ставь за этот источник.
- Один ответ — один префикс (или комбинация `🌐🗄️`). Не дублируй в середине текста.
- Префикс — для человека, не замена цитат и ссылок на источники.

## Примеры

```
🗄️ По вашим заметкам в теме «Финансы»: доход за август — …
```

```
🌐 По данным из открытых источников (поиск сегодня): …
```

```
🌐🗄️ В документации проекта X на сайте — …; в хранилище есть план по cron — …
```

```
💭 Уточните: вас интересует доход за месяц или за год?
```

## Связанные tools (напоминание)

**Хранилище:** `ask_workspace`, `search_and_get_context`, `search_workspace_hybrid`, `search_workspace_content`, `search_workspace_semantic`, `recall_workspace_facts`, `read_content_*`, `read_page_*`.

**Интернет:** `search_web`, `search_web_images`, `read_web_page`, `get_link_preview`, `extract_document_text`.
