# Project — самостоятельный проект внутри vault

Файл вида `<name>.project/README.node.md` — нода-проект.

Папка-проект содержит самостоятельный проект внутри vault. Обычно имеет
собственный `.git`-репозиторий и собственный `.obsidian`-конфиг — то есть
живёт по своим правилам, а не по общим правилам vault.

Внутри допустима произвольная структура (любые папки и файлы).

Отличие от `COMPONENT/REPO`: Project — это **рабочее пространство**,
внутри которого активно ведётся работа. Repo — это лишь **справочная
ссылка-указатель** на папку, в которую агент глубже не идёт.
