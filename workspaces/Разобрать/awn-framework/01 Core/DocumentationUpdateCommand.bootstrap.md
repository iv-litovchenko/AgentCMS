# Команда обновления документации

**Триггер пользователя:** «обнови документацию».

**Что делает:** собирает все файлы `*.documentation.md` из vault в единый файл `./awn.documentation.combined.md` в корне vault.

## Протокол

1. Найти все файлы `*.documentation.md` по всему vault (от корня).
2. Отсортировать их по древовидной структуре каталогов (сначала корень, затем вложенные папки по алфавиту имени).
3. Приоритет — файлам AWN-фреймворка (`01 Core/`, `02 Components/`, `04 Templates/`): они идут в начале выходного файла.
4. Сконкатенировать содержимое всех файлов как разделы книги — каждый файл становится отдельной главой. Yaml-свойства файлов оборачивай в блоки кода ```yaml ... ```.
5. Нумерацию параграфов задавать на основе дерева папок и файлов: `1.`, `1.1.`, `1.1.1.` и т. д. Нумерацию из названий файлов и папок не используй.
6. К каждой главе добавлять ссылку на источник в формате:
   `*Источник: [имя](относительный/путь/к/файлу.md) (строки start-end)*`
   где `start-end` — диапазон строк в исходном файле.
7. Внутритекстовые ссылки на исходные файлы заменять на ссылки на соответствующий параграф итогового документа (если он уже сгенерирован).
8. В начале документа сформировать оглавление со ссылками-якорями на все параграфы.
9. Записать результат в `./awn.documentation.combined.md` (корень vault), перезаписав предыдущую версию.

## Правила

- Пути — относительные от корня vault или от файла-источника.
