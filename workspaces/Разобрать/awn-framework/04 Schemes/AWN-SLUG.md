# Справочник: `AWN-SLUG`

Человекочитаемое имя типа в формате `NAMESPACE/...`. Верхний регистр, разделитель `/`. Slug отражает путь в дереве типов и соответствует вложенности папок в `02 Components/`.

## Неймспейсы

| Неймспейс    | Назначение                       | Примеры                                                    |
| ------------ | -------------------------------- | ---------------------------------------------------------- |
| `COMPONENT/` | Структурные ноды (Folder + File) | `COMPONENT/WORKSPACE`, `COMPONENT/SPACE`, `COMPONENT/PART` |
| `MEMORY/`    | Виды памяти                      | `MEMORY/LOG`, `MEMORY/SIDECAR`, `MEMORY/CONTENT/INNER`     |

## Правила

- В отличие от `AWN-ID`, slug **можно менять** при переименовании типа.
- Связи между файлами идут по `AWN-ID`, а не по slug.

## Используется в

- [Type.schema](Type.schema.md) → поле `AWN-SLUG`
