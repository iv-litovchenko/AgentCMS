Agent

Отлично. Начнём с ваших интересов: работа, здоровье, финансы, хобби? Для каждой области создам area и первые topic со слотами main, inbox и media.

Возможности

Всё, что нужно агенту

Не облачный конструктор и не CMS для сайтов — рабочее пространство, где агент хранит контекст, память и файлы в понятной файловой структуре.

Без базы данных

Каждый агент — папка на диске. Git-friendly, прозрачно, можно открыть в Obsidian или любом редакторе.

Память и контекст

Описания, inbox, TODO, табличная и многофайловая память — всё внутри нод workspace, а не в чате.

MCP для Cursor

Агент читает и пишет контент через MCP tools: страницы, слоты, свойства, загрузка медиа.

YAML-схема

Типы страниц, слоты и поля описаны в awn-system/ — модель CMS встроена в workspace.

Браузер и Desktop

Запуск через npm start или нативное приложение на Electron для macOS.

Agent Shell

Голосовой клиент для работы с агентом — отдельное desktop-приложение в экосистеме Agent CMS.

Экосистема

Два приложения — один workspace

Редактируйте контент в UI, общайтесь голосом через Shell — агент в Cursor работает с теми же файлами через MCP.

Архитектура

PAGE → SLOT → CONTENT

Простая модель: страница (нода) содержит слоты, в слотах — контент нужного типа.

PAGE
topic-1/
↓
SLOT
main media inbox
↓
CONTENT
.md .jpg .yaml
  1. 1
    Выберите агента Workspace на диске — отдельная папка с собственной моделью и контентом.
  2. 2
    Откройте ноду Тема, область или запись — единица контента с описанием, свойствами и файлами.
  3. 3
    Редактируйте слоты main, media, inbox — каждый слот хранит контент своего типа.
  4. 4
    Агент работает через MCP Cursor-агент читает и обновляет workspace без ручного копирования из чата.
Быстрый старт

Запуск за минуту

Клонируйте репозиторий, установите зависимости и откройте редактор в браузере. MCP подключается отдельно — кнопка MCP в шапке UI.

  • Node.js 18+
  • macOS для desktop-сборки
  • Cursor для MCP-интеграции
terminal 
$ git clone <repo> agent-cms
$ cd agent-cms
$ npm install
$ npm start

# → http://localhost:3000
# Desktop: npm run cms:desktop
# MCP:     npm start + mcp-server/
