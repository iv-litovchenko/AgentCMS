**Кратко: да, читать выборочно можно; массово менять — только поштучно (или batch до 10).**

### Чтение только нужных колонок
- **`query_workspace_storage`** — да, параметр `fields: ["awn-focus", "awn-name", ...]` вернёт только эти свойства (+ `path`).
- **`read_page_property` / `read_content_property`** — одно свойство одной записи.
- **`read_*_properties`** — весь frontmatter целиком.

### Как сейчас менять `awn-focus` в нескольких записях
1. **Найти** записи:
   ```json
   query_workspace_storage({
     where: [{ field: "awn-focus", eq: true }],
     fields: ["path", "awn-focus", "awn-name"]
   })
   ```
2. **Изменить** — отдельного bulk-update нет:
   - **UI:** кнопка ⊙ или «В фокусе» — по одной записи.
   - **MCP:** `write_content_property` / `write_page_property` с `key: "awn-focus"`, `value: "true"` или `"false"` — на каждую запись.
   - **Пакетно:** `batch_invoke` с тем же write-tool — до **10** записей за раз (`batch-write-limit`), больше — несколько batch-ов.

Итого: **выборочно читать умеем**, **массово писать — только циклом / batch по 10**, не одной SQL-командой «UPDATE всех».
