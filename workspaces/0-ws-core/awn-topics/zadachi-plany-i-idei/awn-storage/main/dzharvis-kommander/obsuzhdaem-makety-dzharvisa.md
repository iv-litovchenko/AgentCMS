**Что на экране:**

**Как работает:**
- **Голос.** Нажмите на микрофон или пробел. Речь распознаётся по-русски через встроенное в браузер API, ответ Джарвис произносит вслух.
- **Ответы.** Пока они заглушечные: функция `reply()` понимает время, дату, приветствие, свет, погоду и вопрос «кто ты».
- **Подключение своего бэкенда.** В функции `handle()` есть закомментированный `fetch('/api/ask', ...)`. Раскомментируйте его вместо вызова `reply(q)`, и ответы будут приходить от вашего сервера.

**Как это работает**

Модель отвечает JSON вида `{ "title": …, "blocks": [ … ] }`, а `openView(spec)` открывает окно. Справочник этого DSL лежит в окне «Справочник DSL» (кнопка «Копировать» — вставляете в системный промпт). Там же описаны CSS-классы `j-*` на случай, если модель захочет отдать сырой HTML.

**20 типов блоков**

- Текст: `md` (полный markdown — заголовки, списки, задачи, цитаты, таблицы, код), `code`, `alert` (4 тона), `badges`
- Числа: `kpi`, `kv`, `progress`
- `table` — сортировка по заголовкам, фильтр, форматы колонок `num / money / pct / bar / badge / bool / md`
- `chart` — 9 видов на SVG с тултипами: `bar` (группы и stacked), `hbar`, `line`, `area`, `pie`, `donut`, `radar`, `heatmap`, `scatter`
- `form` — все типы полей (text, number, email, date, time, select, radio, range, checkbox, textarea); по submit данные уходят в диалог как сообщение пользователя, и Джарвис их подтверждает
- Списки/статусы: `list`, `timeline`, `steps`, `actions` (кнопки → фраза Джарвису или открытие окна)
- Раскладка: `columns` с весами, `card`, `tabs`, `divider`, `image`, `html`

**Примеры «агент нашёл → визуализировал»** (голосом или через `⌘K` → «Пример: …»)

**Инструменты**
