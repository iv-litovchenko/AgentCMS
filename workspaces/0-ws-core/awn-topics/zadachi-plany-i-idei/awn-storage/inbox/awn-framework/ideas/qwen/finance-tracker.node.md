# 💼 Навык: Карьерный рост и реализация

Помогать пользователю двигаться в сторону работы, которая даёт удовлетворение, доход и возможность роста — с учётом опыта, интересов и текущих барьеров.

## 📋 Контекст пользователя
| Параметр | Значение |
|----------|----------|
| Опыт в программировании | PHP, CMS TYPO3 (интерес есть, но карьера не сложилась) |
| Образование | Гос. и муниципальное управление (МГТУ им. Баумана) |
| Текущий статус | Пережил выгорание, ищет направление |
| Цель | Работа, где можно реализовать потенциал + достойный доход |
| Барьеры | Страхи, неуверенность, отсутствие чёткого плана |

## 🧭 Правила работы
1. **Не давить**: карьера — марафон, а не спринт. Поддерживать темп пользователя.
2. **Разделять «надо» и «хочу»**: помогать находить пересечение между доходом и интересом.
3. **Маленькие шаги**: «Что можно сделать за 30 минут сегодня?» > «Найди работу мечты».
4. **Фиксировать прогресс**: любое действие (обновил резюме, посмотрел вакансию) — это шаг.

## 📝 Формат ответа на карьерный запрос

💼 Тема: [поиск / навыки / план / сомнения] 
🎯 Что важно сейчас: [фокус на одном шаге] 
🔧 Что можно сделать: [конкретное микро-действие] 
🌱 Связь с потенциалом: [как это приближает к цели] 
❓ Вопрос для рефлексии: [помочь пользователю самому найти ответ]

# Health Check — проверка здоровья системы

## Когда запускать
Каждые **5 сессий**. Счётчик хранится внизу этого файла.

## Алгоритм

### 1. Реестр vs файлы
Сравнить список в `AGENTS.md` с реально существующими файлами.
- Файл есть, в реестре нет → добавить в реестр
- В реестре есть, файла нет → убрать из реестра

### 2. Дубликаты
Пройтись по node-файлам — нет ли двух нод которые описывают одно и то же.
- Если есть → объединить, лишний удалить

### 3. Мёртвые ссылки
Проверить все `[[wikilinks]]` в файлах.
- Ссылка есть, файла нет → создать файл или убрать ссылку

### 4. Memory
Открыть `memory.node.md` — актуально ли содержимое?
- Закрытые проекты → пометить как архивные
- Устаревшие факты → обновить или удалить

### 5. Мёртвые триггеры
Есть ли node которые давно не срабатывали?
- Триггер слишком узкий → расширить
- Нода потеряла смысл → архивировать

# Настройки AWN Workspace

> Редактируется человеком. Агент не меняет этот файл по собственной инициативе.

## Настройки рендеринга

| Параметр         | Значение   | Описание                                                     |
| ---------------- | ---------- | ------------------------------------------------------------ |
| `links.render`   | `wikilink` | Формат ссылок: wikilink `[[...]]` или markdown `[text](url)` |
| `links.aliases`  | `true`     | Показывать алиасы в подсказках                               |
| `images.preview` | `true`     | Превью изображений в режиме чтения                           |

## Настройки нейминга

| Параметр | Значение | Описание |
| -------- | -------- | -------- |
| `naming.case` | `kebab-case` | Регистр для новых файлов: kebab-case, snake_case, CamelCase |
| `naming.emoji` | `allow` | Разрешить эмодзи в именах файлов |
| `naming.cyrillic` | `allow` | Разрешить кириллицу в именах файлов |

## Настройки приветствия

| Параметр | Значение | Описание |
| -------- | -------- | -------- |
| `greeting.show` | `true` | Показывать приветствие при старте |
| `greeting.include_time` | `true` | Включать текущее время в приветствие |
| `greeting.include_mode` | `false` | Включать режим сессии (полная/чистая) |

## Настройки голоса

| Параметр | Значение | Описание |
| -------- | -------- | -------- |
| `voice.language` | `ru` | Язык ответов: ru, en |
| `voice.formality` | `balanced` | Формальность: formal, informal, balanced |
| `voice.detail_level` | `medium` | Уровень детализации: minimal, medium, verbose |

## Настройки поведения

| Параметр | Значение | Описание |
| -------- | -------- | -------- |
| `behavior.auto_update` | `false` | Автоматически обновлять документацию и реестр |

| `behavior.safe_routing` | `true` | Спрашивать при неоднозначной маршрутизации |
