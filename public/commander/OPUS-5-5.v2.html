ЧТО ТАКОЕ «ДЖАРВИС» НА САМОМ ДЕЛЕ

    
Это не одна программа, а конвейер из 5–6 независимых модулей, склеенных кодом (обычно Python или Node.js). Каждый модуль можно заменить: облачный на локальный, дешёвый на быстрый. «Мозг» — большая языковая модель (Claude, GPT, Gemini, Llama), которой дали инструменты: управлять домом, компьютером, календарём, искать в интернете. Всё остальное — уши, рот и глаза вокруг неё.

    
Нажми на любой блок, чтобы увидеть, что внутри и какой код обычно пишут.

  

  

  


  

    

      
Бюджет задержки цель: ответ за < 1 сек

      
Главная боль всех джарвисов — пауза между твоей фразой и ответом. Люди хотят, чтобы было как с человеком: ~500–800 мс. Классический конвейер:

      

        
VAD 150

        
STT 200

        
LLM 1-й токен 350

        
TTS 200

≈ 950 мс · хитрость: всё стримится — TTS начинает говорить по первому предложению LLM, не дожидаясь конца.

client = anthropic.Anthropic()

tools = [
  {"name": "set_light", "description": "Вкл/выкл свет в комнате",
   "input_schema": {"type": "object", "properties": {"room": {"type": "string"}, "on": {"type": "boolean"}}}},
  {"name": "get_weather", ...}, {"name": "open_app", ...}, {"name": "remember", ...},
]

while True:
    wait_for_wake_word("jarvis")            # openWakeWord / Porcupine
    text = transcribe(record_until_silence())  # Silero VAD + Whisper
    history.append({"role": "user", "content": text})
    while True:
        r = client.messages.create(model="claude-sonnet-5-5", system=JARVIS_PERSONA,
                                   tools=tools, messages=history, max_tokens=1024)
        history.append({"role": "assistant", "content": r.content})
        if r.stop_reason != "tool_use": break
        history.append({"role": "user", "content": run_tools(r.content)})  # Home Assistant, ОС, API…
    speak(final_text(r))                        # ElevenLabs / Piper — голос «британского дворецкого»

ПЛАН СБОРКИ ШАГ ЗА ШАГОМ

  

    
Текстовый мозг
Чат с LLM в терминале + системный промпт «Ты — Джарвис, вежливый британский дворецкий, отвечай кратко, обращайся «сэр»».

    
Инструменты
Даёшь модели функции (tool use / function calling): погода, время, открыть приложение, поиск. Это то, что делает её «ассистентом», а не болтуном.

    
Уши
Микрофон → VAD режет тишину → Whisper превращает в текст. Потом добавляешь wake word, чтобы слушал постоянно.

    
Голос
TTS со стримингом по предложениям. Выбираешь/клонируешь голос. Добавляешь barge-in: перебил — замолчал.

    
Лицо
HUD в браузере или Electron: ядро-реактор, волна, чат, виджеты. Связь с Python через WebSocket.

    
Навороты
Память, умный дом, зрение, проактивность, MCP-серверы, мульти-агенты. Подключаешь по одному.

Откуда берутся заметки
🎙 разговор → факт в память
📰 статья → конспект + тезисы
🎬 видео → главы и кадры
🤝 встреча → протокол + задачи
✍️ вы сами → заметка голосом

    
Как появляются связи
Сплошные — LLM сама ставит [[ссылки]] при записи.
Пунктир — близость эмбеддингов: заметки похожи по смыслу, хотя ссылок нет.
«Сны» — ночью агент ищет неочевидные связи и утром показывает.

    
Под капотом
Папка Markdown-файлов (совместима с Obsidian) + SQLite с векторами. Граф — d3-force на canvas. Вопрос к мозгу = RAG: поиск ближайших заметок → проход по связям → ответ со ссылками.

import { GestureRecognizer, FilesetResolver } from "@mediapipe/tasks-vision"

const files = await FilesetResolver.forVisionTasks(WASM_URL)
const gr = await GestureRecognizer.createFromOptions(files, {
  baseOptions: { modelAssetPath: "gesture_recognizer.task", delegate: "GPU" },
  runningMode: "VIDEO", numHands: 1 })

function loop() {
  const r = gr.recognizeForVideo(video, performance.now())
  const g = r.gestures[0]?.[0]          // {categoryName:"Thumb_Up", score:0.93}
  const pts = r.landmarks[0]               // 21 точка {x,y,z} от 0 до 1
  if (g?.score > .7) holdThen(600, () => ACTIONS[g.categoryName]())
  if (dist(pts[4], pts[8]) < .05) click(cursorX, cursorY)  // щипок
  if (wristVelocityX() > 1.2) nextDashboard()      // свайп
  requestAnimationFrame(loop)
}

Системный промпт агента-верстальщика

    
UI-кит · виджеты, которые он знает

      
Почему так, а не «пусть пишет любой CSS»: общие токены дают единый стиль, Tailwind-классы модель знает наизусть (их полно в обучающих данных), а JSON-спеку легко проверить. Сырой HTML перед вставкой чистится: без <script> и on*-атрибутов.

  







  

    
ГАЛЕРЕЯ ОТВЕТОВ

    
Современный джарвис не только говорит: он рисует ответ. Модель возвращает не просто текст, а структурированный блок (JSON): «вот диаграмма», «вот график», «вот конспект видео». Интерфейс превращает этот JSON в виджет. Этот приём называют Generative UI.

    
У каждой карточки есть кнопка { } JSON модели: это то, что на самом деле приходит от нейросети. Кнопка «▶ спросить» задаёт тот же вопрос в интерфейсе, с голосом и вызовами инструментов.

  

  







  

    
ДАННЫЕ ВНУТРИ

    
Что хранит и гоняет джарвис под капотом. Это не картинки: история диалога и шина событий живые и обновляются, когда ты общаешься с ним во вкладке «Интерфейс».

  

  

    

      
Граф знаний о тебе тяни узлы мышкой · колесо = зум

      
После каждого разговора отдельный вызов LLM вытаскивает из диалога факты в виде троек (субъект → связь → объект) и кладёт их в графовую БД (Neo4j, networkx или просто SQLite). Потом на вопрос «с кем у меня обед?» он идёт по связям графа.

Векторная память: поиск по смыслу эмбеддинги + косинусная близость

    
Каждое воспоминание превращается в вектор: сотни или тысячи чисел, здесь показаны цветной полоской. Похожие по смыслу фразы дают похожие полоски. Вопрос тоже превращается в вектор, и находятся ближайшие воспоминания (это RAG). Напиши что-нибудь, например «что я пью по утрам» или «машина».

    

    
вектор запроса

    

  


  

    

      
История диалога · messages[] ровно это уходит в API

      
Модель ничего не помнит сама: при каждом запросе ей отправляется вся история, включая вызовы инструментов (tool_use) и их результаты (tool_result). Поговори с ним, и здесь появятся новые записи.

      

    

    

      
Шина событий · WebSocket Python-ядро → HUD

      
Голосовое ядро (Python) и интерфейс (браузер) — разные программы. Они общаются короткими JSON-событиями, а интерфейс по ним перерисовывает реактор, чат и виджеты.
