iframe пустой при открытии файла с диска

Браузер блокирует локальные страницы внутри iframe по протоколу file://. Запустите мини-сервер в папке проекта и откройте hub по HTTP:

cd MyJarvis && ./serve.sh

Затем: http://127.0.0.1:8080/

Или откройте ядро напрямую: composer-2.5.html
