    Горячие клавиши

    • Space удерживать — говорить (PTT)
    • Space коротко — вкл/выкл микрофон (если не PTT)
    • M — mute озвучки
    • C — копировать последний ответ
    • F — полный экран
    • Esc — стоп речи / выйти из ambient
    • R — повторить последний ответ
    • / — фокус в диалоге «Чат»
    • K с Ctrl/Cmd — лаунчер окон
    • Окна: перетаскивание за заголовок, ресайз за угол
    • Голос: «напомни через N минут …», «таймер N минут», «запиши …», «погода»
    • UI Kit: «открой ui kit» · консоль jarvisRenderPanel({…})
