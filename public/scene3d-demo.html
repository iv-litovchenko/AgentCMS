Схема Agent CMS (упрощённый макет — цвета = подписи ниже)

  • Темы — awn-topics, стопка manifest → раздел → запись
  • Workspace — корень хранилища, manifest.md
  • awn-storage — main/, assets/viz/, materials/
  • Viz-карты — цветные плитки (mindmap, flowchart, 3D…)
  • Редактор — UI просмотра и правки записей
  • MCP — API для агента (Cursor и др.)
  • Агент — сфера над схемой (человек + AI)
