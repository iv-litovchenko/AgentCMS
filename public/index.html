          🧩 Agent CMS — система управления контекстом для LLM.
          Одна тема = 1 задача = 1 таблица
        
      
        
      
          Тема — граница смысла: один контекст, одно намерение, одна ответственность.
          Не смешивай задачи в одном файле — разводи их по дереву.
          Память накапливается заметка за заметкой, а система остаётся прозрачной.
          «Файл — это не папка, а намерение.»
        
      
        
      
          Мышление алгоритмами и структурами данных:
          класс = форма, новый тип в системе (пример: цифра),
          объект = экземпляр в «реальном мире» (пример: единица «1»).
        
      
        
      
          Проблема большого контекста: загрузил книгу на 1000 страниц — неизвестно, что LLM посчитает важным, а что нет.
          Без правильных вопросов и без человека не обойтись.
