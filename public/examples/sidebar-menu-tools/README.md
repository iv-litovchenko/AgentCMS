# Sidebar menu tools — compact panel examples

10 standalone HTML demos for compacting the block above the topic tree:

- `.sidebar-slab-menu-tools` — view mode, refresh, collapse, pin, settings, index
- `.sidebar-menu-before-tree` — search bar

## Open

```
http://127.0.0.1:3000/examples/sidebar-menu-tools/
```

Symlink: `public/examples/sidebar-menu-tools` → `examples/sidebar-menu-tools`.

## Variants

| # | Folder | Idea | Target height |
|---|--------|------|---------------|
| 01 | `01-current` | Production layout (two slabs) | ~114px |
| 02 | `02-single-row` | Tools + search in one row | ~40px |
| 03 | `03-overflow-menu` | Search + ⋯ menu for rare actions | ~36px |
| 04 | `04-micro-icons` | Same grid, 24px buttons, tight padding | ~64px |
| 05 | `05-unified-slab` | One white slab, no double border | ~88px |
| 06 | `06-search-trailing` | Icons inside search bar (trailing) | ~38px |
| 07 | `07-search-capsule` | Single pill: search + icon cluster | ~36px |
| 08 | `08-collapsed-band` | Yellow accent band, expands on click | ~36px / ~78px |
| 09 | `09-search-only` | Only search; view via segmented chip in bar | ~34px |
| 10 | `10-dense-two-line` | Mini row 1: views · row 2: search + 3 icons | ~62px |

Gray strip at top mimics collapsed agent hero — only the tools/search zone is the focus.
