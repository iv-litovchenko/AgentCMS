Include / Exclude — раздельно

Два понятных блока. Никакого !file в одной строке с папкой.

✅ Include (scope)

awn-storage/**awn-container/**

Пусто = весь workspace.

⛔ Exclude (always skip)

.git.agent-cmsnode_modules

⚠️ Exceptions (allow inside excluded folder)

ПапкаРазрешить файлы
awn-repository/manifest.md README.md
index-include: [awn-storage/**, awn-container/**] index-exclude: [.git, .agent-cms, node_modules/**] index-exceptions: - path: awn-repository/** allow: [manifest.md, README.md]
