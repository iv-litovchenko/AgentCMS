ui-variant-16 — компактный dock

10 статических макетов того, как уложить элементы production-панели Agent CMS Toolbar (brand-dock + vault): expand, pomodoro, скрин, toggles, CMS, поиск, закладки. Не про раскрытие «иконка → меню» (это ui-variant-12), а про плотность одной полосы.

browser-extension asc-brand-dock mock CSS 10 layouts
Сетка сравнения ui-variant-12 — expand UX

Элементы (как в prod)

  • Бренд + drag, «⊞» развернуть панель инструментов, pomodoro, скрин viewport
  • Toggles: crosshair, page inspector, media hover save
  • Открыть CMS, web-search (picker + поле), черновик закладок
  • Vault workspace — отдельная строка или inline

Локально: cd public/examples/ui-variant-16 && python3 -m http.server 8774
