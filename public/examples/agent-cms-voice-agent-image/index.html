Картинка агента в Agent CMS Voice — 10 точек в UI

Живые макеты: куда можно подставить тот же файл, что питает #agent-preview-thumb в сайдбаре Editor (/api/agents/workspace-preview). Файл кладётся в превью workspace: _Storage/…/preview.jpg (см. AWN Storage) или в слайдер _Assets/slider/.

Запустите npm start и откройте каталог по адресу из консоли (порт не всегда 3000; при редиректе на HTTPS — порт 3443). Путь: /examples/agent-cms-voice-agent-image/ · 15 идей композиции · Без сервера: откройте этот index.html с диска (относительные ссылки на макеты работают).

  • Ширина сайдбара в макетах: 279px — как в проде
  • Подсветка фиолетовой рамкой — зона, куда вставляется workspace-preview
  • Демо-картинка: _agent-thumb.svg (в проде — JPG/PNG из workspace)
