# Example14 — workspace dashboard (линзы, не гирлянда)

## Задача

Показать, как пользователь может собрать **рабочий стол workspace** без превращения Agent CMS в Notion/Obsidian.

Виджет = короткий взгляд на **уже существующие данные** CMS. Не новый тип контента, не embed, не свободная сетка.

## Принципы

| Правило | Почему |
|---------|--------|
| Максимум 4 виджета | Иначе снова «гирлянда» |
| Только привязка к данным | `TODO.md`, inbox, focus, history… |
| Декларативный конфиг | YAML в `manifest.yaml`, не drag-and-drop |
| Каждый виджет → полный экран | один клик до `TODO.md`, Inbox, Карты… |
| Дефолт для всех | кастомизация опциональна |

## Уровни плотности

1. **Сводка** — одна строка pulse (`12 тем · 3 задачи · 5 inbox`)
2. **Виджет** — блок с заголовком и 3–6 строками
3. **Карточка** — быстрый переход (как на `home-pane`)

## Каталог виджетов (MVP)

| type | Источник | Показывает |
|------|----------|------------|
| `todo` | `TODO.md` | открытые `- [ ]`, limit 5 |
| `focus` | focus graph | закреплённые темы |
| `inbox` | inbox slot | счётчик + 2–3 строки |
| `recent` | activity/history | последние правки |
| `topics` | дерево workspace | быстрый доступ (уже есть в `home-pane-2`) |
| `note` | `NOTE.md` | первый абзац |
| `cron` | heartbeat/cron | запланированные задачи |

## Конфиг (черновик)

```yaml
# manifest.yaml
dashboard:
  - type: todo
    title: "Сейчас в работе"
    limit: 5
  - type: focus
    limit: 4
  - type: inbox
    limit: 3
  - type: recent
    limit: 6
```

## Рекомендация

**Главная** (`home-pane`) — витрина: маскот, слоган, 3 карточки.  
**Дашборд** (`home-pane-2`) — рабочий стол с линзами.

Первый виджет для продакшена: **todo** из `TODO.md` — данные и API уже есть.

Запуск: `cd examples && python3 -m http.server 8790` → http://localhost:8790/ui-variant-14/
