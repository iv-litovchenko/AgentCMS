Example14 — workspace dashboard

Как дать пользователю свой рабочий стол в Agent CMS — без превращения в Notion/Obsidian. Виджет = линза на уже существующие данные: TODO.md, inbox, focus, history.

линзы, не гирлянда max 4 виджета YAML в manifest home-pane-2
Открыть прототип →

Идея

  • Главная (home-pane) — витрина: маскот, слоган, 3 карточки.
  • Дашборд (home-pane-2) — рабочий стол с линзами.
  • Виджет не хранит данные — только читает файл/слот и даёт ссылку «открыть полностью».
  • Конфиг декларативный: список type в manifest.yaml, не drag-and-drop.

Анти-гирлянда

  • Нет свободной сетки и embed-ов
  • Нет виджета «пустой текст»
  • Максимум 4 блока + строка pulse
  • Дефолт для всех, кастомизация опциональна
todo

Задачи

3–5 открытых - [ ] из TODO.md. Клик → полный файл.

○ Добавить виджет… ○ Проверить inbox… [все → TODO.md]
focus

В фокусе

Закреплённые темы из focus graph. Уже есть зачаток в home-focus.

inbox

Входящие

Счётчик + 2–3 строки. Не лента на весь экран — только тизер.

recent

Недавно

Последние правки из activity/history. Широкий виджет внизу сетки.

pulse

Сводка

Одна строка: 12 тем · 3 задачи · 5 inbox · 2 cron — не виджет, а шапка.

topics

Быстрый доступ

Карточки тем — уже реализовано в home-pane-2, остаётся под виджетами.
