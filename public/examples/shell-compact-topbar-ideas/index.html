Компактная шапка #shell-compact-topbar — 10 раскладок

Это не ui-variant-N. Отдельный прототип: на странице каталога /examples/ ищите блок «Voice / Shell» сверху или карточку shell-compact-topbar — макеты 01–10 (серый кружок — номер в каталоге, не ui-variant). Здесь варианты именно 01–10 (#v01…#v10). Макеты для side panel / embed (data-compact="1").

Что можно вывести на панели (каталог элементов)

  • Аватар — постер, фазы, hold-to-talk
  • Имя агента
  • Workspace — короткий путь
  • Маршрут — Claude / QwenPaw / Codex
  • Статус фазы — Ожидаю, Думает, Говорит…
  • Последний вопрос
  • Хинт голоса — «Удерживайте»
  • Очередь — «Сейчас …»
  • Контекст — % / токены
  • Превью ответа — 1 строка
  • STT/TTS — режим, пауза
  • Ошибка — OAuth, сеть
  • Часы / батарея — embed
  • Выход — свернуть компакт
