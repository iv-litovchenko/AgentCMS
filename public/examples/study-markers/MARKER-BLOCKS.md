# Блоки `awn-marker-*` в markdown

Многострочные пометки внутри конспекта (палитра CMS: **Маркеры и пометки**).

## Синтаксис

````markdown
```awn-marker-question
awn-status: открыто
awn-create: 2026-09-20
awn-update: 2026-09-25
awn-repeat: 2026-10-01
---
Текст пометки (несколько абзацев, списки).

Вторая строка.
```
````

- **Открытие:** ` ```awn-marker-<type> ` — тип в имени языка fence.
- **Мета (до `---`):** необязательные канонические поля и любые свои `ключ: значение`.
- **Разделитель:** `---` перед телом.
- **Закрытие:** ` ``` ` на отдельной строке.

### Канонические поля (все необязательные)

| Ключ | Назначение |
|------|------------|
| `awn-create` | когда пометка появилась |
| `awn-update` | последнее изменение |
| `awn-status` | состояние (`открыто`, `закрыто`, `отложено`, …) |
| `awn-repeat` | когда повторить / пересмотреть (дата) |

Любые другие строки `ключ: значение` сохраняются как произвольные поля (например `приоритет: высокий`).

В дашборде и preview CMS канонические поля — отдельные чипы; произвольные — только значение. Синонимы: `добавлено`, `обновлено`, `статус`, `повторить`, `awn-review`.

**Legacy (чтение):** `[marker:<type>] … [/marker]` вне обычных fenced blocks.

## Типы (`<type>`)

| type | В дашборде | Иконка |
|------|------------|--------|
| `idea` | мое идея | ★ |
| `important` | мое важно | ! |
| `note` | мое заметка | ✎ |
| `todo` | мое todo | ✓ |
| `question` | мое вопрос | ? |
| `mistake` | мое ошибка | ✕ |
| `term` | мое термин | § |
| `repeat` | мое повторить | ↻ |

- Строки `[мое повторить]: …` + `[мое мета]` по-прежнему собираются.
- Блоки помечаются в UI бейджем типа и цветной полосой слева.
