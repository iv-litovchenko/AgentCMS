# Sidebar menu view placement

10 live examples for where to put the tree / flat / bookmarks mode switcher (🌳 ☰ ⭐) in the current production layout.

Open:

```
http://127.0.0.1:3000/examples/sidebar-menu-view-placement/
```

Symlink: `public/examples/sidebar-menu-view-placement` → `examples/sidebar-menu-view-placement`.

Context: pin, collapse, settings, and refresh are already in the green tree-band header. These demos explore relocating only the view-mode cluster.

| # | Folder | Idea |
|---|--------|------|
| 01 | `01-header-actions` | Compact segment in head, left of pin |
| 02 | `02-header-title-replace` | Replace "Дерево и поиск" title |
| 03 | `03-search-trailing` | Trailing icons on search row |
| 04 | `04-ghost-strip` | Ghost underline strip under search |
| 05 | `05-settings-popover` | Inside settings popover |
| 06 | `06-mode-dropdown` | Single "Режим ▾" dropdown |
| 07 | `07-text-tabs` | Text tabs above index |
| 08 | `08-tree-inline` | Toolbar above `#menu` |
| 09 | `09-hover-reveal` | Hidden until panel hover |
| 10 | `10-sidebar-footer` | Bottom of sidebar |
