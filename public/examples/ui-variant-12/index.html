Example12 — companion toolbar

10 компактных вариантов плавающей панели Agent Shell Companion. Свёрнуто — одна иконка. Клик по иконке раскрывает действия, повторный клик или Esc сворачивает.

клик по иконке icon-first overlay #agent-shell-companion-toolbar
Playground — все 10 Сетка сравнения

Контекст

  • Прод сейчас: отдельная кнопка «Ещё», иконка открывает Side Panel.
  • Эти макеты: иконка = toggle самой панели. Side Panel можно повесить на второй жест позже.
  • Кнопки те же: элемент, страница, чище, markdown, выделение, скрин, промпты.

Запуск: cd public/examples/ui-variant-12 && python3 -m http.server 8773
