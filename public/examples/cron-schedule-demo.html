Два типа runtime-задач

В CMS сейчас есть только повторяющиеся (cron). По расписанию (разово / до даты) — отдельный тип, как в CoPaw jobs.json.

Есть в CMS

Повторяющаяся задача

Флаг awn-runtime-cron + cron-строка. Агент: «загрузи повторяющиеся задачи» → list_workspace_cron.

YAML (frontmatter)
awn-runtime-cron: true awn-runtime-cron-schedule: "0 9 * * 1-5"
Mock / CoPaw

Задача по расписанию

Разовый запуск или серия «каждый день до даты». Живёт в jobs.json планировщика агента, не в cron-поле CMS.

jobs.json → schedule
{ "type": "once", "run_at": "2026-08-20T20:00:00", "timezone": "Europe/Moscow" }
Команда агенту
«загрузи задачи по расписанию»
