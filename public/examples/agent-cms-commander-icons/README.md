# Agent CMS Commander — черновики иконки

Иконки для будущего **Agent CMS Commander** (управление ПК), в стиле карточек Launcher (64×64).

Открыть:

```
/examples/agent-cms-commander-icons/
```

Или двойной клик по `index.html` в этой папке.

На странице: серия 01–05, развитие 05b–05f, десять вариантов v01–v10. Красным отмечены отклонённые, зелёным — финалисты **v01** и **v07**.
