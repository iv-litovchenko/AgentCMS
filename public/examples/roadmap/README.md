# Дорожная карта обучения из Markdown

Скрипт строит горизонтальную схему этапов изучения темы из одного markdown-файла.

## Синтаксис

```markdown
# Java — дорожная карта

## Основы синтаксиса
статус: завершено
Переменные, типы, циклы…

## Базы данных
статус: в процессе
JDBC, транзакции…

[параллельная группа]

## Объектно-ориентированное программирование
статус: в процессе
Классы, наследование…

## Многопоточность
статус: не начато
Thread, synchronized…

## Фреймворки
статус: не начато
Spring Boot, REST…
```

### Статусы

| Значение | Цвет блока |
|----------|------------|
| `не начато` | серый |
| `в процессе` | жёлтый |
| `завершено` | зелёный |

### Параллельные ветки

Маркер `[параллельная группа]` перед серией `##`-заголовков объединяет этапы в один столбец — их можно проходить одновременно. После группы следующий `##` снова идёт линейно.

## Запуск

### HTML-пример

```bash
open examples/roadmap/04-roadmap.html
```

### CLI

```bash
cd public/examples/roadmap
node build-roadmap.js -i sample-roadmap/java-learning.md
node build-roadmap.js -i sample-roadmap/java-learning.md -o report.html
```

## Файлы

| Файл | Назначение |
|------|------------|
| `sample-roadmap/java-learning.md` | Входной файл с 5 этапами (2 параллельных) |
| `build-roadmap.js` | Парсер и генератор HTML |
| `04-roadmap.html` | Интерактивный пример |
