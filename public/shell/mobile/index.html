Как это связано

iPhone Shell
    ↓ Wi‑Fi

    ↓ messageTarget
QwenPaw (:8088)
    ↓ MCP tools
CMS workspace (agent-cms-test)
  • Shell — только голос/текст и ответ на экране.
  • CMS — роутер: какой workspace и куда слать.
  • QwenPaw — LLM, который отвечает.
  • MCP — «руки» QwenPaw в файлах CMS (настроен в QwenPaw).

Маршрут задаётся в desktop Shell или в .agent-shell/settings.json (сейчас обычно QwenPaw).

Микрофон в Safari

  1. Важно: по http://192.168… Safari не спрашивает микрофон. Нужен HTTPS на порту 3443 — на Mac: npm run start:https, на iPhone: https://IP:3443/shell/mobile/.
  2. Нажмите 🎤 — начнётся запись; нажмите 🎤 ещё раз — запись остановится и текст отправится.
  3. Нажмите Разрешить, если Safari спросит.
  4. Если отказали: Настройки → Safari → Микрофон → для этого сайта «Спросить» или «Разрешить».
  5. Настройки → Конфиденциальность → Микрофон — Safari включён.

Mac и iPhone — одна Wi‑Fi. CMS: HOST=0.0.0.0 npm start
