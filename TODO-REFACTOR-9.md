# Рефакторинг — часть 9

**Цель:** переименовать системные папки в `workspaces/`.

| Сейчас | План |
| ------ | ---- |
| `agent-cms-core` | **`0-ws-core`** |
| `agent-cms-test` | **`0-ws-test`** |
| `cli-sandbox` | **`0-cli-sandbox`** |

## Зачем

1. **Не «agent»** — это хранилища (workspace), как у пользователя.
2. **`0-`** — системные каталоги **сверху** списка; пользовательские ws **ниже**.
3. **`ws`** — коротко: workspace (`0-ws-core`, `0-ws-test`).
4. **`0-cli-sandbox`** — отдельная папка под **запуски CLI** (как сейчас `cli-sandbox`); **`0-`** только для сортировки вверх.

## Не в scope

- Переименование пользовательских хранилищ.
- REFACTOR-5 (бренд продукта).

## Миграция

- Папки на диске, пути в скриптах/тестах/дефолтах, реестр.
- Legacy alias: `agent-cms-core`, `agent-cms-test`, `cli-sandbox`.
