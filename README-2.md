# AGENT CMS
Agent CMS — программа для хранения заметок, документов и других данных вместе с ИИ-агентом. Всё лежит в обычных файлах на диске (текст, таблицы настроек), без отдельной базы данных. Вы работаете через окно в браузере или desktop-приложение; агент — через подключение в Cursor или другой среде. Видите одно и то же содержимое.

## Зачем
Заметки, файлы и ссылки часто разбросаны по разным программам. В обычном чате с ИИ контекст не сохраняется между сессиями. Здесь материалы лежат в одном месте с понятной структурой: и вы, и агент знаете, где что искать и куда класть новое. Данные остаются у вас на диске, их можно копировать и версионировать как обычные файлы.

## Как устроено — основные термины

**Хранилище (workspace)** — папка вашего проекта: разделы меню, темы, файлы с текстом и вложениями. У каждого агента может быть своё хранилище.

**Платформа** — общая часть программы: типы записей, справочники и настройки, которые действуют для всех хранилищ.

**Дерево** — раздел → тема → полка (слот) → файл-запись. Пример: «Работа» → «Ремонт» → «Документы» → `смета.md`. Структуру выстраиваете вы; жёсткого шаблона нет.

**Накопители (инфоблоки)** — для таблиц и списков с одинаковыми полями (расходы, контакты, справочники). Для свободных заметок и текстов удобнее дерево.

**Служебное** — пароли в `.env`; временные индексы и кэш поиска в скрытой папке `.agent-cms/` (можно не коммитить в git).
