# Agent CMS — для пользователя (NotebookLM)

> **Версия 2 — пользовательская.** Без технических деталей, без «как это устроено под капотом».  
> Техническая выжимка для разработчиков и агентов: `README.NOTEBOOK-LM.md`  
> **Дата:** 2026-09-20

---

## Что это такое

**Agent CMS** — ваш общий «умный шкаф» для жизни, работы и проектов, к которому имеет доступ и **вы**, и **AI-помощник**.

Вы раскладываете заметки, документы, задачи и идеи — как в Notion или на диске.  
AI видит **то же самое**: может искать, дополнять, напоминать, помогать с текстами и организацией.

Главное отличие от обычного облака:

> **Нет двух отдельных миров** — «мои файлы» и «память чата». Одно общее пространство.

Коротко:

> **Google Drive + Notion + постоянный AI-помощник** — в одном месте.

---

## Зачем это нужно

Сейчас информация обычно разбросана:

Telegram → заметки → Google Drive → Obsidian → файлы на компьютере → закладки → голова.

AI при этом каждый раз «не в курсе», где лежат ваши реальные данные, и вы заново объясняете контекст.

Agent CMS собирает всё в **одно хранилище**, где:

- вы ведёте дела руками через удобный интерфейс;
- AI работает с теми же материалами;
- поиск находит нужное по смыслу, а не только по названию папки;
- можно говорить с помощником голосом, с телефона или из браузера.

## Как устроено — простая аналогия

Представьте **большой шкаф с рабочим столом**:

| Что в системе | Как думать об этом |
|---------------|-------------------|
| **Хранилище (workspace)** | Весь шкаф целиком — «Работа», «Личное», «Проект X» |
| **Область** | Большой отдел шкафа: «Финансы», «Здоровье», «Клиенты» |
| **Тема** | Конкретная полка: «Путешествие в Италию», «Книга», «CRM салона» |
| **Раздел внутри темы** | Ящики на полке: «Основное», «Входящие», «Фото», «Заметки», «Диалоги» |
| **Запись / файл** | Лист бумаги или документ в ящике |

У каждой **темы** может быть:

- **описание** — о чём это, зачем, какие правила;
- **свойства** — статус, теги, дата, приоритет, цвет и др.;
- **записи** — тексты, заметки, статьи;
- **файлы** — картинки, PDF, вложения;
- **обсуждение** — переписка по этой теме.

## С чего начать

### 1. Откройте Agent CMS

- **В браузере** — после запуска приложения на компьютере (обычно локальный адрес вроде `https://localhost:3443`).
- **Desktop-приложение** — «Agent CMS» на Mac/Windows/Linux (иконка редактора).
- **Пульт Control** — отдельное приложение для запуска сервера и сборок, если вы не разработчик — можно просто пользоваться готовым `.app`.

### 2. Выберите хранилище

Слева в меню — список **хранилищ** (workspace).  
Это отдельные «шкафы»: личное, работа, тестовое, проект клиента.

Переключились — видите своё дерево тем.

### 3. Откройте тему в дереве

Слева — **дерево**: области → темы → иногда вложенные разделы.

Кликнули на тему — справа открывается её содержимое: описание, записи, файлы, свойства.

### 4. Сохраняйте изменения

После правок нажмите **Сохранить** (или используйте привычное сочетание клавиш, если настроено).

## Интерфейс — что где находится

### Левая панель (меню)

- **Переключение хранилища** — разные «шкафы».
- **Дерево тем** — основная навигация.
- **Режимы дерева** — обычное дерево, плоский список, карточки с превью, избранное ⭐.
- **Поиск по меню** — быстро найти тему по названию.
- **NOTE.md / TODO.md** — общие заметки и задачи на всё хранилище (не привязаны к одной теме).
- **Журнал, факты, диалоги** — служебные разделы (см. ниже).

### Верхняя часть экрана

- **Хлебные крошки** — где вы сейчас: хранилище › область › тема › запись.
- **Поиск по содержимому** — ищет по тексту и смыслу по всему хранилищу или внутри выбранной темы (можно «прикрепить» тему к поиску).
- **Кнопки справки** — документация, подсказки по Markdown.

### Рабочая область (центр)

Когда открыта тема, обычно доступны группы:

| Группа | Для чего |
|--------|----------|
| **Обзор** | Краткая карта темы: что внутри, связи, статистика |
| **Описание / настройки** | Главный текст темы, правила, инструкции для AI |
| **Память** | Записи, заметки, основные материалы |
| **Входящие** | Всё, что ещё не разложено по местам |
| **Файлы / медиа** | Картинки, документы, вложения |
| **Свойства** | Поля записи: статус, теги, даты, приоритет… |
| **Обсуждение** | Диалог по этой теме — вы и AI |
| **Комментарии** | Короткие пометки к записи или странице |

Вертикальная **панель иконок** слева от контента переключает эти режимы.

## Как организовать информацию

### Свободные заметки и документы

Подходит для:

- протоколов встреч;
- черновиков статей;
- личных дневников;
- README проекта;
- любых текстов «как получится».

Создайте **тему** → раздел **Память / Основное** → новую **запись**.

### Входящие (inbox)

Когда что-то прилетело и некуда сразу положить:

1. Бросьте в **Входящие**.
2. Позже разберите: оставить, перенести в другую тему, удалить.

Так не теряются быстрые мысли из чата, голоса или браузера.

### Структурированные списки

Когда нужны **одинаковые поля у всех элементов**:

- список задач с дедлайнами;
- каталог услуг;
- реестр клиентов;
- расходы по месяцам.

Для этого в Agent CMS есть **накопители (инфоблоки)** — по сути таблицы и карточки с фиксированными колонками.  
В меню они живут отдельно от обычных тем.

**Простое правило:**

- **свободный текст** → тема + запись;
- **одинаковые поля у всех строк** → накопитель / инфоблок.

### Пример из жизни

| Задача | Куда класть |
|--------|-------------|
| Конспект лекции | Тема «Обучение» → Память |
| Список покупок на неделю | Тема «Дом» → TODO или запись |
| Клиенты салона с телефонами | Накопитель «Клиенты» |
| Фото с отпуска | Тема «Отпуск 2026» → Медиа |
| «Потом разобрать» | Входящие |

## Работа с AI-помощником

### Одна память

AI не «живёт в отдельном чате с amnesia». Он читает ваши темы, записи и свойства — если вы дали ему доступ к этому хранилищу.

Вы правите в интерфейсе → AI видит изменения.  
AI дописал заметку → вы видите её в той же теме.

### Где общаться

| Место | Когда использовать |
|-------|-------------------|
| **Cursor / Claude Desktop** | Глубокая работа: код, большие тексты, автоматизация |
| **Agent Shell (голос)** | Быстрые вопросы, задачи «на ходу», озвучка ответов |
| **Обсуждение темы** | Переписка именно по одному проекту |
| **NOTE.md** | Общая доска: «напомни завтра», «идея на потом» |

### Что полезно делать AI

- «Найди всё про X в теме Y»
- «Допиши черновик встречи»
- «Разложи входящие по темам»
- «Сделай конспект из этих записей»
- «Напомни, что мы решили по проекту Z»

### Банк фактов 🧠

Отдельное место для **коротких выводов**, которые стоит помнить долго:

- «Мы решили делать так-то»
- «Пользователь предпочитает короткие ответы»
- «API проекта: такой-то URL»

Это не архив всей переписки — только **важные итоги**.

### Журнал и колокольчик 🔔

**Журнал** — лента событий: что изменилось, что сделал AI, что отметили вы.  
**Колокольчик** — уведомления из журнала: не пропустить важное.

## Голосовой помощник (Agent Shell)

**Agent Shell** — отдельное окно или приложение для разговора с AI:

- говорите — текст уходит помощнику;
- ответ показывается на экране и **озвучивается**;
- можно пользоваться с **телефона** (Safari или iOS-приложение);
- есть **расширение для Chrome** — панель на любой странице в интернете.

### Типичный сценарий

1. Открыли Shell на Mac или телефоне.
2. Сказали: «Добавь в TODO купить билеты».
3. AI записал в ваше хранилище — вы проверили в Agent CMS.

Shell **не заменяет** полноценный редактор — он для быстрого общения и команд.

## Поиск — как найти нужное

Не обязательно помнить, в какой папке лежит файл.

- **Поиск в шапке** — по словам и по **смыслу** («где мы обсуждали бюджет?»).
- **Ограничение темой** — перетащите тему из меню в поле поиска, чтобы искать только внутри неё.
- **Связи между записями** — можно посмотреть, кто на что ссылается (как «обратные ссылки» в Obsidian).

## Свойства записей — зачем они

У записей и тем могут быть **поля** помимо текста:

| Поле | Пример использования |
|------|---------------------|
| Статус | open / done / archive |
| Теги | `#работа`, `#идея` |
| Приоритет | высокий / низкий |
| Дата | дедлайн, дата создания |
| Цвет | визуально выделить в списке |
| Превью | картинка на карточке в меню |

Из полей складываются **фильтры и обзоры** — например, «все открытые задачи с высоким приоритетом».

## Дополнительные материалы к записи

У одной заметки может быть **своя маленькая папка** — черновики, схемы, приложения только к ней.  
Не путать с общей «медиатекой» всей темы: это личные материалы **одной** записи.

## Типичный день с Agent CMS

**Утро**

- Открыли колокольчик — что изменилось за ночь.
- Пробежались по TODO.md.
- Спросили AI голосом: «Что горит сегодня?»

**День**

- Записали мысли во **Входящие**.
- Вели проект в теме с **Памятью** и **Обсуждением**.
- AI помог оформить протокол встречи.

**Вечер**

- Разобрали входящие — перенесли по темам.
- AI сохранил итог дня в **банк фактов** или в журнал.
- Добавили задачи на завтра в TODO.

## NotebookLM — зачем этот файл

Google **NotebookLM** хорошо работает с **выжимками и конспектами**.

В Agent CMS для этого есть раздел **NotebookLM** внутри темы — туда кладут материалы, подготовленные специально для загрузки в NotebookLM:

- конспекты серии статей;
- выжимки по проекту;
- «шпаргалка для себя через полгода».

Этот файл — **общая пользовательская выжимка о системе**.  
Техническая версия для разработчиков — в `README.NOTEBOOK-LM.md`.

## Частые вопросы

**Это замена Notion?**  
Частично — для заметок, проектов и AI-памяти. Notion удобнее для публичных wiki и совместной работы команды «из коробки». Agent CMS сильнее там, где нужен **ваш AI с доступом к файлам**.

**Нужно ли быть программистом?**  
Нет для повседневного использования. Редактор рассчитан на обычные тексты и свойства. Технические возможности — для тех, кому они нужны.

**AI точно видит всё?**  
Только то хранилище и те темы, к которым вы подключили помощника. Можно держать несколько «шкафов» — личное отдельно, работа отдельно.

**Чем отличается от Obsidian?**  
Obsidian — отличный личный блокнот. Agent CMS — блокнот **+ встроенный AI-рабочий процесс** (inbox, факты, журнал, голос, обсуждения по темам).

**Можно ли потерять данные?**  
Контент лежит обычными файлами на диске. Имеет смысл делать резервные копии хранилища так же, как для любых важных документов.
