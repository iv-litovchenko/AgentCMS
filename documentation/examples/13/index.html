Example13 — куда деть слоты hub-rail

10 способов убрать node-navigation-hub-rail из центральной колонки, когда уже заняты: дерево слева · контент по центру · диалог справа.

Проблема сейчас — четвёртая колонка внутри workspace:
[ Дерево 250px ] | [ Hero + контент ~350px | ⟨ | Rail слотов 300px ] | [ Диалог 350px ] ↑ на экране 1280px контенту остаётся <300px — rail съедает всё

Запуск: cd documentation/examples && python3 -m http.server 8790 → http://localhost:8790/13/

01 · рекомендуем

Chips под hero-nav

Слоты (📥163 · 📒0 · 🖼3) — горизонтальные chips прямо под «← Предыдущая / Следующая →». Rail убран, центр на всю ширину.

[дерево] | [hero-nav + chips + контент] | [диалог]

02

Вкладки вместо rail

Один активный слот: Обзор · Входящие · Заметки · Медиа. Список файлов — в основной зоне, не в боковой колонке.

[дерево] | [tabs + список/контент] | [диалог]
Открыть прототип →
03 · рекомендуем

Слоты в дерево

Под нодой «Тест 1000 сообщений» — папки 📥 Входящие, 📒 Заметки, 🖼 Медиа. Левая колонка становится навигатором по слотам.

[дерево+слоты] | [чистый контент] | [диалог]

04

Слоты в потоке документа

Rail исчезает: каждый слот — секция в scroll (accordion или labeled dividers). Подходит для overview-страницы.

[дерево] | [hero + 📥секция + 📒секция + 🖼секция] | [диалог]

05

Flyout overlay

Узкая кнопка «Слоты» или иконка 📦 — панель 280px поверх контента, не сжимая его. Закрывается кликом вне.

[дерево] | [контент full width + flyout поверх] | [диалог]

06

Нижний drawer

Слоты в выдвижной панели снизу (как VS Code terminal). Центр всегда широкий, rail не нужен.

Bento-dashboard

Слоты — плитки в сетке внутри main: inbox-card, notes-card, media-grid. Нет отдельной колонки.

[дерево] | [hero + bento 2×3] | [диалог]

08

Icon dock (свёрнутый rail)

Rail по умолчанию collapsed: 6 иконок × 40px между контентом и диалогом. Раскрытие — только активного слота.

09

Mega-menu / Command palette

Одна кнопка «Слоты ▾» или ⌘K — все слоты и файлы в overlay. Центр чистый, rail не нужен вообще.

Правая колонка = вкладки

Объединить диалог и слоты: [💬 Обсуждение | 📥 Входящие | 🖼 Медиа]. Одна правая панель, два режима — не четыре колонки.
