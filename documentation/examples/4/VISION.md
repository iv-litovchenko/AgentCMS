# Examples4 — как устроена навигация ноды

## Пять доменов (не шесть)

В production сейчас смешаны «Медиа» и «Файлы». В этой серии прототипов заложена **пятёрка**, ближе к тому, как пользователь думает о ноде:

| Домен | Иконка | Зона `_Storage` | Смысл |
|--------|--------|-----------------|--------|
| **Навигация** | 🧭 | граф, MOC, индекс | *Где я в пространстве ноды?* Не редактор текста. |
| **Память** | 🧠 | Inbox, _Content, internal, TODO | *Что знает агент?* Основная работа с md. |
| **Вложения** | 📎 | _Assets, _Preview | *Какие файлы прикреплены?* Списки, превью, sidecar. |
| **Настройки** | ⚙️ | описание, Configuration, _Scripts, .env | *Как устроена нода?* Меняют реже. |
| **Автоматизация** | ⚡ | расписание, heartbeat | *Что делает нода сама?* Отдельно от «настроек». |

«Дополнительно» (векторизация и т.п.) — не домен первого уровня, а пункт меню агента / будущий раздел.

---

## Принципы

1. **Домен ≠ вкладка браузера** — один клик переключает *тип работы* (память → вложения), а не только вид списка.
2. **Подрежимы всегда видны** — после выбора домена пользователь видит flyout или второй ряд (Внешняя / TODO / …).
3. **Навигация не съедает workspace** — граф и MOC живут в блоке «Содержимое», как сейчас с режимом «Граф».
4. **Частое отделено от редкого** — Память + Вложения + Навигация в одном кластере; Настройки + Авто ниже (варианты 01, 07, 25).

## Рекомендуемая схема (вариант 25)

```
┌─────────────┬──┬──────────────┬────────────────────────────┐
│ Дерево нод  │🧭│  Память      │  Крошки                    │
│             │🧠│  › Внешняя   │  🧠 Память › Внешняя       │
│             │📎│  Внутренняя  │  ┌──────────────────────┐  │
│             │──│  TODO        │  │ Содержимое / граф /   │  │
│             │⚙️│              │  │ список файлов         │  │
│             │⚡│              │  └──────────────────────┘  │
└─────────────┴──┴──────────────┴────────────────────────────┘
```

- **Rail:** кластер 🧭 🧠 📎 сверху, разделитель, ⚙️ ⚡ снизу.
- **Flyout:** заголовок домена + подсказка + список подрежимов.
- **Workspace:** крошки + строка контекста (`домен › режим`) + превью содержимого без лишнего «текстового» редактора там, где он не нужен (вложения, граф).

Это совпадает с текущим Agent CMS после переноса графа в «Навигация», с переименованием группы «Файлы» → «Вложения».

## Когда смотреть другие варианты

| Задача | Варианты |
|--------|----------|
| Мало места по горизонтали | 03, 23 — вкладки и два ряда pills |

## Связь с Examples3

- **Examples3** — полный layout (крошки, свойства, редактор, 6 групп).
- **Examples4** — только **навигация по пяти доменам**; содержимое заменено превью-панелью.

После выбора варианта навигации его можно встроить в макет из Examples3 (например, 25-production-blend + Examples4/25).
