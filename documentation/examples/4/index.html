Examples4 — навигация по доменам

25 прототипов только навигации ноды: как показать пять доменов (Навигация · Память · Вложения · Настройки · Автоматизация) и переключать подрежимы. Содержимое — превью-панель, не полный редактор.

🧭 Навигация 🧠 Память 📎 Вложения ⚙️ Настройки ⚡ Автоматизация

Как я это вижу (кратко)

Навигация — мета-слой: граф, MOC, индекс. Не хранит текст заметки, а показывает связи.

Память — основной рабочий домен (80% времени): inbox, _Content, internal, TODO.

Вложения — бинарники и превью (_Assets, _Preview), без «Содержимое»-редактора для списков.

Настройки — редкий домен: описание ноды, конфиги, скрипты, .env — ниже по rail.

Автоматизация — самый редкий: расписание, heartbeat — отдельно от настроек.

Рекомендация: вариант 25 (кластер 🧭🧠📎 + flyout + контекст в содержимом). Подробнее: VISION.md.

Запуск: cd documentation/examples/4 && python3 -m http.server 8768 → http://localhost:8768 · node generate.mjs
