Example9 — хлебные крошки + select + действия

25 прототипов шапки workspace: как совместить select подрежима, хлебные крошки (служебные / обычные / доменные) и служебные кнопки (Сохранить, Удалить, Просмотр…). В каждом варианте переключатель контекста сверху.

Служебный файл Обычные крошки Настройки ноды Память ноды Обзор ноды

Три типа навигации

  • Служебные файлы — docker-compose.yml, AGENTS.md: путь + 🔒 + Save, без select и Delete.
  • Обычные крошки — документ в дереве без доменного префixа.
  • Крошки документа и раздела — префix «Настройки/Память/Обзор» + select подрежима + путь.

Рекомендация: вариант 25 или 01 — одна строка, как в текущем Agent CMS.

Запуск: cd documentation/examples/9 && python3 -m http.server 8770 → http://localhost:8770 · node generate.mjs
