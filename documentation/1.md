## API для быстрых тестов (curl)

```bash
# Создать тему в Vault (агент test3)
curl -s -X POST "http://localhost:3000/api/node/create?agent=test3" \
  -H "Content-Type: application/json" \
  -d '{"parentPath":"_Vault","type":"file","name":"TestTopic"}'

# Память summary — не должен создавать Content.md из манифеста
curl -s "http://localhost:3000/api/memory/summary?agent=test3&path=TestTopic.x.md"
ls -la workspaces/test3/_Storage/TestTopic 2>/dev/null || echo "OK: bundle нет"
```
