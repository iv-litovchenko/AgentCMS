### Вот самые популярные плагины с такой логикой:

* Download with Free Download Manager — перехватывает любые типы файлов (или только заданные расширения) и автоматически отправляет их на скачивание в бесплатную программу Free Download Manager (FDM).

* IDM Integration Module — официальное расширение для популярного менеджера Internet Download Manager (IDM). Полностью заменяет стандартный загрузчик Chrome своей оберткой, умеет перехватывать видео и аудио со страниц.

* Chrono Download Manager — полностью меняет стандартный интерфейс загрузок Chrome на продвинутый менеджер прямо внутри браузера (без стороннего софта на ПК), позволяя гибко настраивать правила перехвата.

* External Download Manager (или аналогичные Open Source решения) — расширения, которые позволяют связать Chrome практически с любым внешним загрузчиком (например, Aria2, wget или вашим собственным скриптом).
